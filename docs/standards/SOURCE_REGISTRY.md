[Playwright 공식 테스트 작성 안내](https://playwright.dev/docs/writing-tests)와 KSTQB 공식 시험 범위·샘플 문제는 학습 자료로 원문 링크만 연결한다. 교육 수료증과 시험 자격을 구분하며 기관 로고·교재를 복제하지 않는다.

## 캘린더 지역 파생 근거

공개 커뮤니티 좌표를 일시 처리해 국내/해외/미확인을 파생하며 좌표 자체는 저장·표시하지 않습니다. 실제 행사장 국가가 아닌 주최 커뮤니티 지역입니다. 미확인 좌표와 대한민국 경계 인근의 모호한 점은 미확인으로 남깁니다. 기본 국내·온라인은 국내 행사와 전 세계 온라인 행사를 함께 포함합니다.

로컬 scripts/data/korea-boundary.json은 [Natural Earth 공식 벡터 저장소](https://github.com/nvkelso/natural-earth-vector)의 50m 국가 자료에서 대한민국 형상만 추출했습니다. [공식 이용 조건](https://www.naturalearthdata.com/about/terms-of-use/)은 public domain입니다. 원본 URL·라이선스를 JSON에 보존하며 실행 때 외부 지도 API를 호출하지 않습니다.

## 국내 출처 추가 검토와 정적 교육 근거 (2026-10-26)

2026-10-31 한국지능정보사회진흥원(NIA)의 [AI허브 데이터 분석 교육 공고](https://www.nia.or.kr/site/nia_kor/ex/bbs/View.do?bcIdx=29909&cbIdx=99835)에서 교육일과 신청 기간이 명시된 사례를 확인했다. 해당 공고는 이미 종료되었으며, 공지 목록의 안정적인 자동 수집 경로와 robots·재사용 조건은 확인되지 않아 수집 출처로 추가하지 않았다. 향후 실제 공고의 조건을 확인하고 날짜를 추출할 때 게시일을 신청 마감으로 추정하지 않는다.

NAVER D2의 공식 Atom(https://d2.naver.com/d2.atom)은 20개 항목을 읽었다. 정책 확인은 완료되지 않았다(robots.txt 406). 자동 수집에는 아직 추가하지 않았으며, 기존 활성 출처와 허가·키 제외 원칙을 유지한다.

교육·인증 자료는 src/data/certifications.ts의 learningFee / credentialFee / requirements / evidenceUrls / verifiedAt을 함께 관리한다. 검토일은 모든 필드의 확정 보장이 아니다. 미확인을 무료로 바꾸거나 무료 영상 청강을 무료 수료증으로 간주하지 않는다. 전수 재검토·정정 근거는 [교육 검토 결과](../archive/EDUCATION_ACCESSIBILITY_2026-10-26.md)를 따른다. 자동 수집 대상에 추가한 것은 아니다.

## 무료 기초 강의 정적 안내 (2026-10-26)

부스트코스 7개와 성균관대 SKKU Online 2개를 제목·제공 기관·비용 상태·기간·공식 링크 중심의 정적 교육 자료로 추가했다. 강의 영상·교안·이미지를 복제하지 않고 설명은 탐색용으로 작성했다. 온라인 수료증 표시를 무료 발급으로 단정하지 않으며 미발급은 별도 상태로 구분한다. 강좌별 근거와 기간은 [무료 강의 확충 결과](../archive/FREE_COURSES_2026-10-26.md)를 참조한다. 정적 강의 추가 자체는 행사 자동 수집 출처 확대가 아니다.
