# 직무 둘러보기와 추천 커리큘럼 발전 설계

기준일: 2026-10-31. 직무 둘러보기는 초기 구현, 분야별 추천 커리큘럼 개편은 사용자 요청으로 보류한다.

## 조사와 설계 근거

- [커리어넷](https://www.career.go.kr/cloud/m/job/view?seq=10117)은 직업 개요·하는 일·능력과 관련 직업을 제공한다. 국내 직업 설명의 참고 출처이며 표현을 그대로 대량 복제하지 않는다.
- [O*NET QA 직무](https://www.onetonline.org/link/summary/15-1253.00)는 업무와 역량을 분리한다. 미국 기준 정보이므로 한국 채용 조건·임금으로 전용하지 않는다.
- [Microsoft Learn 데이터 분석가 경로](https://learn.microsoft.com/en-us/training/career-paths/data-analyst)는 직무, 역량과 학습·자격을 연결한다. 자사 기술 중심이라는 점을 고려해 우리 서비스는 다양한 제공처 자료를 연결한다.
- [고용24](https://www.work24.go.kr/)는 채용행사·채용박람회를 제공한다. 최초 화면은 공식 사이트 링크만 제공하고, 개별 행사는 공식 원문에서 행사명·주최·일자·장소·신청 조건을 검증하기 전 표시하지 않는다. 정기 수집·캘린더 통합·외부 API는 별도 출처 및 권리 검토 후 결정한다.

## 현재 직무 화면

학습관·홈에서 `/careers`로 진입해 QA, 데이터 분석, AI 엔지니어, 정보보안 직무를 살펴본다. 상세는 업무·관련 역량·작은 체험·학습 검색·선택 자격과 원문 출처를 제공한다. 설명과 역량은 편집한 예시이며 기업별 차이를 안내하고 취업·소득이나 자격의 필수성을 보장하지 않는다. 자료 검색어와 자격 ID를 통해 기존 페이지를 사용하며 로그인·진도·개인정보 저장은 없다.

행사는 고용24로 연결한다. 이용 가능한 개별 행사를 검증하지 못한 경우 확인 중으로 표시하고 날짜나 모집 상태를 만들어 내지 않는다. 국민내일배움카드 훈련은 직무 목록과 상세에서 고용24 과정 검색·카드 안내 및 검토된 회차 예시를 제공한다. 확인일을 표시하고 훈련 시작일이 지나면 예시를 숨긴다. 모집·비용·자격은 원문에서 확인하며 공식 수료증을 확인하지 않은 훈련을 수료증 취득 강의로 취급하지 않는다.

## 보류 중인 분야별 추천 커리큘럼

기존 `/path`를 발전시켜 분야 선택 → 기초 학습 → 실습 → 선택 가능한 수료 과정·자격 → 심화·프로젝트를 제시하는 안을 계획한다. 예: 데이터 분석은 데이터 기초·파이썬 → 정리 실습 → 선택 자격 → 분석 프로젝트, QA는 테스트 기초 → 테스트 설계 실습 → 선택 자격 → 자동화·AI 테스트. 이 내용은 확정된 필수 순서나 구현 완료 기능이 아니다.

향후 데이터는 직무·역량·자료·과정·자격·프로젝트·행사를 별도 항목으로 관리하고 안정적인 ID로 다대다 연결한다. 자료별 출처·언어·비용·선행 조건·확인일을 각 원본에서 참조해 중복 복사를 피한다. 개별 자료의 중단·조건 변경 시 연결을 점검하며, 내용이 부족한 단계는 추천을 꾸며내지 않고 비워 둔다. 신규 직무·주제와 이후 개발 항목은 검증된 근거와 함께 연결한다. 퀴즈·진도·개인화 저장은 현행 제외 범위다.

## 후속 검토

- 한국 직무별 공식 출처와 용어를 추가하고 검토일·근거를 보강한다.
- 국내에서 참여 가능한 채용행사 원문을 검증한 뒤 상세에 배치한다. 채용행사와 자격 시험 일정은 별개이며 자격 시험 캘린더 연동 취소 결정은 유지한다.
- 추천 자료 검색 링크 대신 개별 내부 상세 연결을 지원할지 검토한다.
- 로드맵 구현 전 데이터 구조·유지 관리와 디자인을 별도로 확정한다.
