# AI 허브릿지 홈: 지식의 다리와 디지털 전시관

2026-10-29 기획 시안. A 지식의 다리와 C 탐색 지도를 결합하고 디지털 전시관의 분위기를 더한다. 사용자 검토용 제안이며 실제 홈이나 메뉴는 아직 바뀌지 않았다.

## 경험의 흐름

1. 첫 화면에서 방문자 가까이 시작하는 다리가 멀리 있는 전시관 입구로 이어진다. 다리가 브랜드의 대표 이미지이며 길을 안내한다.
2. 전시관 안의 네 영역은 AI 소식, AI 캘린더, 추천 커리큘럼, 교육·인증을 상징한다. 실제 자료 목록은 대시보드와 각 페이지에 둔다.
3. 아래로 내려가면 네 영역을 짧은 시각 장면으로 소개한다. 각 영역은 해당 기존 페이지로 연결하고, 주 버튼은 대시보드로 연결하는 안이다.

## 첫 화면

- 제안 문구: **AI의 세계로 이어지는 다리** / **소식부터 배움까지, 한곳에서 만나다.**
- 주 버튼: `대시보드 보기`. 로고는 홍보 홈 `/`, 대시보드는 별도 메뉴와 `/dashboard` 제안.
- 데스크톱: 왼쪽에 제목과 버튼, 오른쪽에 다리와 전시관. 네 공간의 표시는 건물 내부 또는 아래 설명 구간에 배치한다. 제목과 버튼의 가독성이 장면보다 우선한다.
- 시각 방향: 밝은 흰색과 짙은 청색, 절제된 하늘색·호박색. 전시관은 친근하고 열린 지식 공간으로 표현한다. 완성 시안에서 실제 로고와 기존 테마를 고려한다.
- 생성 이미지의 `행사 일정`, `학습 콘텐츠`, `교육·자격`은 분위기 참고용 임시 문구다. 실제 화면은 `AI 캘린더`, `추천 커리큘럼`, `교육·인증`으로 고친다. 가상의 검색 기능이나 실제 존재하지 않는 메뉴도 넣지 않는다.

## 지도와 전시관

다리는 ‘정보에 도달하는 경로’, 네 공간은 ‘무엇을 볼 수 있는지’를 보여준다. 복잡한 지도 조작을 요구하지 않고, 그림과 별도의 명확한 링크로 각 공간을 선택하게 한다. 지도 자체가 기능인 것처럼 오해되지 않게 한다. 전시물은 자료의 종류를 상징하는 도형과 실제 화면을 단순화한 그래픽을 사용한다. 생성 이미지에 등장하는 임의의 기사·행사·통계는 실제 데이터로 취급하지 않는다.

## 움직임과 반응형

- 첫 진입 시 다리의 빛이나 선이 입구 방향으로 한 번 흐르고 전시관이 드러난다. 1~1.5초 내외의 제안이며 제목과 버튼은 처음부터 보인다.
- 각 전시 영역에 마우스를 올리거나 키보드로 초점을 맞추면 해당 영역만 은은하게 강조한다. 클릭이나 탭으로 실제 링크를 연다.
- 움직임 줄이기 설정에서는 완성된 정적 장면을 바로 표시한다. 자동 이동·스크롤 가로채기·계속 반복하는 빛은 사용하지 않는다.
- 모바일에서는 제목·버튼을 먼저 보여주고 다리와 입구를 단순화한 세로 장면을 아래에 배치한다. 네 목적지는 읽을 수 있는 독립 링크로 재배열한다.

## 제작과 검증 계획

이번 생성 이미지는 **분위기 검토용**이다. 최종 서비스 이미지는 권리와 용량을 확인하고, 필요하면 별도의 자체 그래픽 또는 SVG/CSS 장면으로 제작한다. 사진처럼 보이는 전시관이 실제 건물이나 실제 운영 시설이라는 인상을 주지 않도록 조정한다. 라이트·다크 테마, 320px 이상 화면, 링크 키보드 조작, 모션 감소, 이미지 로딩 실패 시 문구와 버튼, GitHub Pages 하위 경로를 확인한다.

기존 홈의 최근 소식과 로딩·오류·빈 상태를 대시보드로 보존한다. 기존 소식·캘린더·학습 데이터, 수집, 개인정보, 네트워크 정책은 이 디자인 제안만으로 변경하지 않는다. 새 홈 구현과 URL 변경은 시안 검토 후 진행한다.
