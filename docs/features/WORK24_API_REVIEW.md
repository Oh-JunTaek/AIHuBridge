# 고용24 API 활용 검토

기준일: 2026-11-01. 서비스별 승인은 사용자 제공 화면 기준이며, 실제 응답과 공개 서비스 운영 범위는 별도 확인이 필요하다. 인증키는 저장소나 대화에 기록하지 않는다.

| API | 판단 | 우리 서비스에서의 용도 |
|---|---|---|
| 국민내일배움카드 훈련과정 | 우선 | 직무별 훈련 후보와 공식 상세 링크. 시작일과 모집 마감을 혼동하지 않는다. |
| 직업정보 | 우선 검토 | 직무 둘러보기의 하는 일·필요 역량에 한국 공식 출처를 보강한다. 직업 분류와 현재 직무 간 대응을 검토한다. |
| 직무정보 | 우선 검토 | 표준직무기술서·직무데이터사전으로 업무와 역량을 뒷받침한다. 직업정보와 중복·분류 단위를 확인한다. |
| 공통코드 | 기반 | 훈련 NCS 및 채용 분류·지역의 공식 코드를 확인하고 필터에 이용한다. |
| 구직자취업역량 강화프로그램 | 검토 | 구직자 대상 프로그램을 직무 탐색에서 소개한다. 날짜·접수 상태와 참여 조건이 제공되는지 확인한다. |
| 채용정보 | 채용행사 우선 검토 | 채용행사·박람회 연결은 기존 기획과 부합한다. 채용공고 확대는 제공 대상과 이용 조건을 별도 확인한다. |
| 일학습병행 훈련과정 | 후순위 | 실무 연계 교육 후보. 입사·재직 및 참여 조건을 확인해 일반 공개 과정과 구분한다. |
| 사업주훈련 훈련과정 | 후순위 | 사업주·재직자 대상 여부와 개인 신청 가능성을 검증한 경우에만 소개한다. |
| 국가인적자원개발 컨소시엄 훈련과정 | 후순위 | 협약기업·참여대상 등 제한이 있는 과정은 조건을 확인해 제한적으로 소개한다. |
| 강소기업 | 보류 | 채용 중이거나 직무에 적합하다는 뜻은 아니다. 별도 기업 탐색 기능의 필요성이 생기면 검토한다. |

출처: [고용24 API 목록](https://www.work24.go.kr/cm/e/a/0110/selectOpenApiIntro.do?bbsClCd=OosccI71O3P2dBxVz5A40Q%3D%3D), [훈련과정 명세](https://www.work24.go.kr/cm/e/a/0110/selectOpenApiSvcInfo.do?fullApiSvcId=000000000000000000000000000004), [구직자 프로그램 명세](https://www.work24.go.kr/cm/e/a/0110/selectOpenApiSvcInfo.do?fullApiSvcId=000000000000000000000000000098).

채용정보 API는 [고용24 FAQ](https://m.work24.go.kr/cm/c/g/0100/customerSearch.do?keyword=%EC%B1%84%EC%9A%A9%EA%B3%B5%EA%B3%A0)에 제공 대상 제한이 안내되어 있다. 발급 사실만으로 개별 채용공고 재배포까지 확정하지 않고 승인 범위와 조건을 확인한다. 승인받은 각 API에 동일 키가 적용되는지도 실제 호출 전에는 단정하지 않는다. 제공된 화면에는 11개 중 10개만 보이므로 마지막 항목은 미확인이다.
