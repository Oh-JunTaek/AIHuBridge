# 달력 유형 뱃지·경계 날짜 표시 개선

2026-10-28 사용자 요청과 추가 답변을 반영했다. 현재 표시 정책의 정본은 [자료 노출 기준](../standards/CONTENT_LIFECYCLE.md), 구현 상태는 [PLAN](../../PLAN.md)을 따른다.

## 변경 결과

- 기존에는 장기 일정이 시작일부터 종료일까지 모든 날짜를 점유하고 행사 제목을 반복했다. 이제 확인된 신청 시작·마감, 행사 시작·종료 날짜만 표시한다. 사용자 예시인 신청 1일·마감 5일·개최 7일은 세 날짜에 표시한다.
- 같은 날 같은 유형은 하나의 뱃지로 묶고 추가 건수를 표시한다. 2개 해커톤은 ‘해커톤 +1’이다. 같은 행사의 시작·종료 등 여러 기준이 같은 날이면 유형별 건수와 날짜 총 건수에는 한 번만 센다.
- 뱃지 툴팁은 행사 제목·그날의 날짜 기준·취소/연기·변경 전 참고 여부를 담는다. 모바일은 한 글자로 축약하고 하단 범례와 전체 유형명·건수 접근성 이름을 제공한다. 날짜 선택으로 상세 목록을 확인한다.
- 선택 월·날짜 목록도 같은 경계 날짜 기준이다. 중간 달에는 나타나지 않는 장기 일정도 ‘전체 기간’ 검색으로 찾을 수 있다. 상세 카드의 명시적 행사 종료 시각도 표시한다.
- 수집 데이터·자동화·보관 기한은 바꾸지 않았다. 종료일이나 마감일을 추정하지 않는다.
