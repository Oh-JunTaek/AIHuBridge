# 다리·전시관 홈 구현 결과 (2026-10-29)

- 사용자 승인 시안의 전시관과 다리를 바탕으로 생성한 글자 없는 이미지를 WebP로 저장하고 `/` 홈 배경으로 적용했다. 네 기능으로 연결하는 소개와 대시보드 버튼을 추가했다.
- 이전 홈의 최근 소식 화면은 `/dashboard`로 옮기고 메뉴에 추가했다. 기존 소식 수집과 필터 로직을 변경하지 않았다.
- 공통 stone 색상을 청회색으로 조정하고 헤더와 메뉴를 정리했다. 기능별 화면은 기존 레이아웃을 유지하므로 각 화면을 전시관 스타일로 개별 재설계한 것은 아니다.
- 데스크톱 로컬 브라우저에서 홈 표시와 대시보드 이동·실제 소식 표시를 확인했다. 320px 홈의 제목·버튼 가독성을 확인하고 수정했다. 다크·키보드·접근성 및 공개 배포 환경은 별도 확인이 필요하다.
- 90개 테스트, lint, selfcheck, build 통과. 기존 Tailwind 소스맵 경고 발생. 새 애니메이션의 화면 검증은 남아 있다.
