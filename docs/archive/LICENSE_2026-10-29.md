# MIT 라이선스 파일·공개 원문 정비

2026-10-29 개발계획의 P2 코드 라이선스 파일 누락 항목을 처리했다. 기존 사용자 결정과 package.json·약관의 MIT 선언을 구체화한 것이며 새 라이선스로 변경한 것이 아니다.

## 변경

- 루트 [LICENSE](../../LICENSE)에 [OSI MIT 표준 원문](https://opensource.org/license/mit)을 추가했다. 프로젝트 기여자 저작권 고지와 허가·면책 원문을 보존했다.
- postbuild에서 루트 LICENSE를 dist/LICENSE.txt로 복사한다. 브라우저에서 텍스트로 열도록 .txt 확장자를 사용한다. 수동 배포 사본을 추가하지 않으며 누락 시 빌드 후처리가 실패한다.
- 약관 적용일과 외부 패키지 권리 안내를 갱신하고 BASE_URL 아래 라이선스 원문을 여는 링크를 제공했다.
- [권리·재사용 안내](../standards/RIGHTS.md)에 프로젝트 코드·문서와 외부 소식·논문·강의·행사·상표·이미지·소프트웨어 패키지의 적용 범위를 구분했다. Natural Earth의 기존 출처·공개 도메인 표기도 유지한다.
- README·PLAN을 갱신했다. 외부 콘텐츠나 모든 의존성의 권리 전수 감사를 완료했다고 표시하지 않는다.

## 검증과 범위

타입 포함 빌드·selfcheck를 통과했고 루트 LICENSE와 dist/LICENSE.txt의 전체 내용 일치, package.json의 MIT 선언을 검사했다. 배포 빌드 미리보기에서 약관의 BASE_URL 링크·새 탭 표시와 정적 원문을 확인했다. 기존 Tailwind sourcemap 경고는 남지만 빌드는 성공했다.

브라우저에서 /AIHuBridge/LICENSE.txt가 다운로드 대신 텍스트 원문으로 열리는 것을 확인했다. [약관 화면 증거](../../artifacts/license-terms-2026-10-29.png)를 남겼다.

직전 메뉴 작업 8c1a5fa는 사용자 승인으로 푸시했고 배포 40789436112 성공·공개 빌드 일치까지 확인했다. 이 라이선스 정비는 후속 작업의 로컬 구현·검증·커밋 범위이며 아직 원격에 반영하지 않았다.
