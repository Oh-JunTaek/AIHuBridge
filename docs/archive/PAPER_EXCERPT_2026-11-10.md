# 논문 초록 표시 정돈

2026-11-10 로컬 구현. 논문 저장소 출처의 카드에서 arXiv RSS의 `arXiv:... Announce Type: ... Abstract:` 관리용 머리말을 제거하고 원문 초록을 표시한다. 저장된 원문·링크·검색·분류 정보는 변경하지 않는다.

- 충분히 긴 완성 문장이 제한 길이 안에 있으면 문장 끝에서 마치고, 없으면 단어 경계에서 생략 표시를 더한다. 화면의 두 줄 제한은 유지한다.
- 수식은 그대로 두며 번역·LLM 요약·연구 성과 또는 중요도 판정은 하지 않는다. 원본 수집 당시 잘린 초록의 뒷부분을 복구하지는 못한다.
- 단위 검사 3건, PC·모바일 폭 브라우저 관련 4건, 타입 검사와 빌드 통과. 실제 스크린리더·운영 배포는 검증하지 않았다.
