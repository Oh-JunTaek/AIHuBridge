# AI 자격증과 모바일 탐색

- 학습관에 `/qualifications`를 추가했다. 자격시험 17개 항목을 분야·자격 종류·시험 언어·명칭/주관사로 탐색하고 상세 팝업에서 시험 비용, 응시 조건, 갱신, 준비 자료와 공식 안내를 확인한다. 일부 필드는 미확인으로 두었다. 한국 예약 가능성은 예약처 확인 안내이며 실제 예약을 검증한 것은 아니다.
- NVIDIA NCA Generative AI LLMs, AICE Basic·Associate, KPC AI-POT·AIBT·GTQ-AI, AWS·Microsoft·Google 인증 및 관련 데이터 자격을 포함했다. AICE Generative는 공식 일정의 B2B 전용 표시로 개인 대상 확인 전 제외했다. SQLD 갱신 시점은 과거 안내를 현재 조건으로 단정하지 않는다. 일정 수집·캘린더 연동은 제외한다.
- 교육·인증의 시험 탭을 신규 페이지 링크로 대체하고, 기존 시험 자료 5건을 자격 목록으로 옮겼다. 커리큘럼에서 해당 시험 상세로 연결하며 수강 과정·실습 배지는 기존 교육·인증에 남긴다.
- 모바일 메뉴 글자를 제거하고 상위 메뉴 첫 터치에 하위 메뉴, 두 번째 터치에 첫 페이지를 연다. 모바일 전환은 0.2초, 화면 아래 콘텐츠는 스크롤 시 짧게 나타나며 움직임 줄이기 환경에서는 동작하지 않는다.
- 검증: 타입 검사, 테스트·자체 점검·빌드, 로컬 브라우저의 데스크톱/320px 검색·상세·닫기·직접 링크를 확인했다. 실제 모바일 기기·터치·스크린리더 및 해외 시험 예약 과정은 검증하지 않았다. 공식 소개 중 짧은 인용을 확인한 항목 외에는 출처 기반 간단한 사실 설명을 사용한다.
