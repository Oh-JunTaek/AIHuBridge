# 캐러셀과 모바일 탐색 개선

- 홈 전시 카드의 스크롤 막대를 숨기고 양옆 전체 높이에 이전·다음 이동 영역을 배치했다. 중앙 카드를 강조하고 양끝을 점차 흐리게 처리하며, 손가락 스크롤과 키보드 포커스도 지원한다. 움직임 줄이기 설정에서는 부드러운 이동을 생략한다.
- TOP 버튼에 불투명한 흰색 배경을 적용했다.
- 모바일의 소식, 일정, 추천 커리큘럼, 교육·인증 필터를 접을 수 있게 하고 접힌 상태에서 선택 조건을 요약한다. 데스크톱에서는 기존처럼 필터를 펼쳐 둔다.
- 학습관과 정보관 이름을 누르면 각각 첫 하위 항목으로 이동한다. 별도 하위 메뉴 버튼을 제공해 터치와 키보드에서도 다른 항목에 접근할 수 있다. 마우스 올리기와 기존 순차 표시 시간은 유지한다.
- 글꼴 변경은 전체 디자인을 확인한 뒤 결정한다.

검증: 타입 검사, 전체 테스트, 자체 점검과 프로덕션 빌드를 수행했다. 로컬 브라우저에서 데스크톱 및 320px 화면의 캐러셀, 모바일 필터 선택 요약과 상위 메뉴 이동을 확인했다. 실제 모바일 기기 검증은 별도로 하지 않았다.
