## 반영한 결정

- 운영 주소는 `https://oh-juntaek.github.io/AIHuBridge/path`이며 사용자 확인상 정상 배포 중이다. 현재 배포 경로와 학습 경로는 유지했다.
- 로컬 모델 기능은 프론트·수집기·사용 안내에서 제거했다. 웹 이용자가 모델이나 별도 서버를 설치할 필요가 없다.
- 뉴스 설명은 RSS 제공 설명문을 규칙으로 발췌한다. 자동 번역·생성형 요약을 제공한다고 안내하지 않는다.
- 이번 결과는 로컬 변경이며 푸시·배포·원격 Actions 실행은 하지 않았다.

## 구현 내용

### 로컬 모델 제거

- 사용되지 않던 `src/lib/summary.ts` 삭제.
- 뉴스 수집기의 모델 호출·모델 선택 환경변수·로컬 서버 주소 제거.
- 진단 화면·문자열·메타에서 모델 티어와 활성화 안내 제거.
- README·PLAN·CHECKLIST·AGENTS를 현재 웹 서비스 기준으로 갱신. 이전 분석은 당시 기록으로 보존하고 후속 정정 링크 추가.
- 일반 AI 학습 콘텐츠의 LLM 용어·강좌명은 서비스 실행 의존성과 무관하므로 유지.

### 행사 수집

- 수집 변환을 `scripts/lib/calendar-collector.mjs`로 분리하여 실제 입력 사례를 회귀 검사한다.
- 현재 활성 출처는 카카오 공식 RSS 1곳이다. JSON을 RSS로 읽던 주소, 실재·목적이 확인되지 않은 주소, 일반 기술 글을 행사로 취급하던 고정 분류를 제거했다.
- AI 관련 행사 유형·모집 표현·명시적 신청 마감일을 함께 요구한다. 게시일을 신청일이나 행사일로 복사하지 않는다.
- 지원하는 날짜 표현은 연도를 포함한 한국어 라벨 형식이다. 날짜만 있는 마감은 한국시간 해당 날짜 끝으로 해석한다. 지원하지 않는 시간 표현·상대 날짜·충돌하는 마감일은 추정하지 않는다.
- 이미 마감했거나 시작한 행사, 일반 글, 다시보기, 중복, 샘플을 공개 목록에서 제외한다.
- 비용·장소·지역·온라인 여부는 확인되지 않으면 미확인으로 유지한다. RSS 출처에 따른 일괄 무료·오프라인·서울 처리를 제거했다.
- 원문 게시일·수집 시각·사람의 내용 확인일을 구분한다. 자동 추출 항목은 수동 확인 전이라고 표시한다.
- 일부 출처 실패 시 해당 출처의 이전 검증 데이터 중 미마감 공고만 유지한다. 전체 실패는 오류로 종료하고 기존 JSON을 덮어쓰지 않는다. 정상 수집 결과 0건은 허용한다.
- 샘플 fallback과 이를 재삽입할 수 있는 루트 임시 치환 스크립트 2개, 깨진 과거 검사 로그 파일 `2`를 제거했다.

### 웹 표시·공통 수집

- 수집기와 브라우저가 `src/lib/calendar-rules.mjs`의 같은 스키마·마감 기준을 사용한다.
- 브라우저에서 1초마다 현재 시각을 갱신하여 페이지를 열어 둔 사이에 마감된 공고도 제외한다.
- 한국시간 날짜 차이로 D-day를 계산하며 실제 마감 시각이 지나면 즉시 종료로 판단한다.
- 정상 0건·로딩·오류·오래된 수집·일부 출처 실패를 안내하고 요청 실패 시 재시도를 제공한다.
- 진단 페이지의 `/dev` 라우트 등록 누락과 메타 요청 경로를 수정했다. 홈의 로딩 종료 시점도 실제 뉴스 요청 완료 뒤로 이동했다.
- 공통 RSS HTTP 로더는 15초 제한·4 MiB 본문 제한을 적용한다. RSS 파서는 XML 해석에만 사용한다. 기존 parseURL 기반 실행에서 프로세스가 남는 현상을 확인했고 새 로더의 전체 수집 종료를 재확인했다.
- 뉴스 수집 0건은 기존 파일 보존 후 실패로 보고하며 URL 중복을 제거한다.
- JSON은 임시 파일 작성 후 교체한다. 파일별 교체이므로 여러 JSON 전체에 대한 트랜잭션을 보장하는 구조는 아니다. 후속 selfcheck에서 메타 일치를 검사한다.
- 예약 수집 워크플로의 커밋 대상을 뉴스·행사 JSON/메타 4종으로 확대하고 테스트·타입·데이터·빌드 검사를 추가했다. Node 버전은 22로 맞췄다.

## 남은 한계와 후속 작업

1. 행사 수집 범위가 카카오 공식 RSS 1곳으로 제한되어 있다. 정부·교육기관·행사 전용 공식 출처를 실제 응답과 일정 제공 형식까지 확인한 뒤 추가해야 한다. 카드 수를 채우기 위해 미확인 출처를 되살리지 않는다.
2. 한국어의 제한된 명시적 날짜 형식을 지원한다. 영어 공고·축약 날짜·상대 날짜·일정 변경/취소의 상세 해석은 미지원이다. 자동 추출 공고는 신청 전에 원문 확인이 필요하다.
3. 예약 수집 봇 커밋 후 공개 사이트에 자동 배포하는 연결은 기존과 동일하게 별도 과제다. 현재 운영 사이트 정상 동작과 예약 데이터 갱신의 종단간 검증은 구분한다.
4. 교육기관 16건의 가격·무료 수료증 조건 재검증, 뉴스의 상세 오류 상태, 모바일 메뉴·접근성 전수 검사는 이번 범위에서 완료하지 않았다.
5. 생성형 번역·요약은 현재 제거한 상태다. 향후 필요하면 웹에서 사전 처리한 정적 결과를 제공하는 구조와 비용·운영 정책부터 검토한다. 현재 외부 계정·키 제한을 임의로 변경하지 않는다.
