# 모델 발표 후보 묶음 및 분류 보완

2026-11-10 로컬 구현. 수집한 기사나 URL을 삭제하지 않고, 소식 화면에서 선택된 결과만 묶는다. 모든 출처의 기사는 펼쳐 확인하고, 개별 기사에 해당하는 검색·필터는 묶기 전에 적용한다. 한 기사만 조건에 맞으면 그 기사만 표시한다. 화면의 기사 건수와 묶음 건수는 구분한다.

- 모델명과 버전이 명확한 K-엑사원, 카나나-2-v-디사이드, GPT·Claude·Gemini·Qwen·Llama·Gemma 일부 표기와 출시·API 개방 표현을 조합한다. 같은 모델이라도 API 개방과 모델 공개는 따로 두고 3일을 넘는 기사는 묶지 않는다. 논문·전망·이름 또는 버전 미확인은 묶지 않는다. 공식 개발사 출처가 같은 묶음 안에 있으면 대표로 표시한다.
- 묶음은 **관련 보도 후보**이며 같은 사건이라고 보증하지 않는다. 상이한 사건이 묶이거나 같은 사건이 분리될 수 있다. 특히 현재 규칙은 위 식별자만 다루므로 새로운 모델의 별도 보도는 대부분 묶이지 않는다. 근거 없는 전체 기사 병합을 피하기 위한 초기 범위다.
- 모델 출시 판별에서 제목의 포괄적인 ‘신규/new’ 하나만으로 출시를 판단하지 않고 출시·발표 표현을 요구한다. 출시일 전망·예상 문구도 제외한다. 보수적 규칙이므로 실제 발표도 빠질 수 있으며, 모델 검색 전용 신규 RSS에 동일 규칙이 적용된다. 이미 저장된 JSON을 강제 덮어쓰지 않았다.
- 수집 당시 `origin/data-refresh` 1,132건 스냅샷을 대상으로 실행했을 때 1,123개 묶음이었으며, 엑사원 API 관련 기사 4건·엑사원 공개 2건·카나나 발표 6건이 각각 후보로 묶였다. Qwen 4 출시일 전망 표본은 모델 출시에서 제외됐다. 이 결과는 전체 정확도·재현율 평가가 아니다.
- 단위 검사 129건 통과·1건 건너뜀, 관련 PC·모바일 폭 브라우저 검사 6건, 타입 검사·selfcheck·빌드 통과. 브라우저 검사는 고정된 표본이며 실제 예약 수집·운영 배포와 다르다.

후속: 수집 데이터의 모델명·사건 유형에 대한 별도 정답 표본을 늘려 과도한 묶음과 놓친 묶음을 함께 측정하고, 관련 발표·공식 원문의 확인 가능한 연결 방식을 확장한다. LLM이나 새 외부 서비스는 사용하지 않았다.
