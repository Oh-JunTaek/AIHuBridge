## 이번 확정 범위

- 캘린더 본문 max-w-6xl(1152px)과 헤더 max-w-4xl(896px)의 불일치가 로고를 안쪽으로 보이게 한 원인이었다. 캘린더 경로에서 헤더도 1152px로 맞췄다. 좁은 화면은 화면 폭을 함께 따르고 다른 페이지는 기존 896px 헤더를 유지한다.
- 캘린더 대분류: 국내 / 해외 / 지역 미확인 / 전체. 사용자 확정에 따라 기본 국내는 국내 행사뿐 아니라 전 세계 온라인 행사도 포함한다. 해외 오프라인·혼합/미확인 방식은 기본 화면에서 제외한다. 초기화도 이 기본값으로 돌아온다. 대분류는 통계·달력·목록에 함께 적용하며 선택을 개인 설정으로 저장하지 않는다.
- AI뉴스 제목의 ‘리서치’를 AI뉴스로 수정하고 블로그 탭을 모델 소식으로 교체했다. 개발자 메뉴는 계속 숨긴 상태다.
- 전체 기사 / 국내 기사만 구분과 모든 분야에 맞는 세부 필터, 24개씩 더 보기를 추가했다. 뉴스의 기본 출처 범위는 전체다. 국내는 국내·한국어 편집 출처 기준이며 한국 사건만 뜻하거나 언어 판별 결과를 뜻하지 않는다.
- 기업 SNS는 구현하지 않고 PLAN에 후속 계획만 작성했다. 회사 공식 및 CEO·관계자 개인 계정 포함. 공지/예고/추측 또는 관련성 판단으로 미리 제외하지 않고 허용된 게시물을 모아 방문자가 기업·제품·작성자·채널·키워드·기간으로 직접 거른다. SNS 계정·키·유료 API·새 메뉴는 추가하지 않았다.

## 캘린더 지역 근거

공개 Google 일정에는 국가 필드가 없다. 수집 시 공개 커뮤니티 위치와 Natural Earth의 공개 도메인 대한민국 경계를 비교해 territory를 파생한다. 좌표는 저장·표시하지 않고 국내/해외/미확인 및 주최 커뮤니티 기준이라는 근거만 남긴다. 도심의 명시적 국내 도시 표기는 화면에서도 참고한다. 커뮤니티의 지역은 실제 행사장 위치·입장 자격·온라인 접속 가능 국가를 보증하지 않는다. 해안·섬 경계 인근의 모호한 점과 잘못된 좌표는 미확인으로 남긴다. 한국어 제목으로 국내라고 추정하지 않는다.

데이터: scripts/data/korea-boundary.json. [Natural Earth 이용 조건](https://www.naturalearthdata.com/about/terms-of-use/)은 지도 자료를 public domain으로 제공한다. 저장한 대한민국 형상만 수집기에 사용하므로 정기 실행마다 별도 지도 API를 호출하지 않는다.

국내/전체, 언어, 출처, 검색은 공통 적용한다. 분야를 바꾸면 해당 분야의 세부 조건을 초기화해 숨겨진 필터가 남지 않게 했다. 모든 선택은 현재 화면 상태다.

분류는 원문 분류 코드와 제목·짧은 설명문의 규칙/키워드로 수행한다. LLM·번역 API·계정·키·개인화는 없다. 공개 방식은 오픈소스 언급 / 가중치 공개 언급 / 비공개 언급 / 미확인·혼합이다. 출처가 Hugging Face라는 이유로 오픈소스라고 가정하지 않는다. 라이선스를 확인한 결과가 아니며, 복수 모델의 혼합 표현·키워드의 문맥 오류·누락이 있을 수 있다.

## 소식 수집 확장과 논문 0건 원인

- 기존 arXiv 주소의 휴일 RSS가 실제 빈 목록이었다. 날짜를 만들어 채우는 대신 공식 rss.arxiv.org의 AI·언어·시각·머신러닝·음성 통합 RSS와 공식 최근 제출 Atom을 사용한다.
- RSS가 비거나 날짜가 확인되지 않거나 요청이 실패하면 3초 간격 뒤 공식 Atom 최근 제출 40건을 확인한다. 발행 후 7일 이내 논문을 원문 분야별로 나눠 최대 24건 선택한다. 중요도·획기성·성능을 자동 점수화하지 않는다. PDF를 복제하거나 동료평가 통과를 보장하지 않는다.
- arXiv의 [RSS 안내](https://info.arxiv.org/help/rss.html)와 [메타데이터·호출 조건](https://info.arxiv.org/help/api/tou.html)을 확인했다. 메타데이터와 원문 연결만 사용하며 기관당 3초 간격·한 연결 원칙을 지킨다. RSS와 Atom 모두 실패하면 기존 7일 이내 자료를 보존하는 출처별 실패 처리로 돌아간다.
- 모델 소식에는 OpenAI·Google DeepMind·Mistral 공식 RSS 발표와 Hugging Face 공개 플랫폼 글을 포함한다. 전부 언론 보도라고 표시하지 않고 개발사 공식 발표/커뮤니티/매체/논문 원문으로 구분한다. Anthropic·Meta 등의 비공식 생성 RSS를 공식 피드로 추가하지 않았다.
- 국내는 Google 뉴스 한국어 외에 공식 홈페이지가 연결한 긱뉴스·AI타임스 RSS를 추가했다. 긱뉴스는 AI 관련 항목만 고른다. 두 신규 국내 출처는 제목·날짜·원문 링크만 저장하고 요약 본문을 재게시하지 않는다. AI타임스 RSS는 홈페이지 HTML의 rel=alternate에 있는 cdn.aitimes.com/rss/gn_rss_allArticle.xml이다.
- 출처 수와 한도는 news-sources.mjs에서 관리한다. 기본 8건, 공식 모델 관련 피드 16건, 신규 국내 12건, 논문 24건이다. 일부 실패 보존은 각 출처 한도를 따르며 발행 후 7일 제한을 유지한다. 전체 실패·전체 0건은 파일 교체를 막는다.
