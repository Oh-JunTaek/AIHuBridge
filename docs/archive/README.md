# 과거 이력 보관소

이 폴더의 문서는 작성 당시의 분석, 검증, 작업 기록 또는 인수인계 스냅샷이다. **현재 기능이나 에이전트 작업 지시의 우선 출처가 아니다.**

현재 정책: 루트 [AGENTS.md](../../AGENTS.md), [PLAN.md](../../PLAN.md), [README.md](../../README.md), `docs/operations/`, `docs/standards/` 참조.

- `HANDOFF_2026-10-27.md`는 최근 작업 스냅샷이며, 당시 커밋과 배포 상태를 현재 사실로 간주하지 않는다.
- `CHECKLIST_2026-10-26.md`의 완료 체크는 당시 검증 시점의 기록이다. 기능 진행 상황은 PLAN 한 곳에서 관리한다.
- 날짜별 결과 보고서의 옛 규칙은 현재 확정 정책과 다를 수 있다.
- `originals/`에는 첨부된 문서의 **원본 사본**을 수정하지 않고 보관한다.

열람용 사본은 과거 기록 경고와 이동에 따른 상대 링크만 보정했다. originals는 보정하지 않는다. 과거 결과의 숫자·정책·다음 작업을 현재 정본에 자동 복제하지 않는다. 2026-10-28 사용자 재확정 및 정리 결과는 [충돌 정리 보고서](./CONSISTENCY_REVIEW_2026-10-28.md)에 있다.
