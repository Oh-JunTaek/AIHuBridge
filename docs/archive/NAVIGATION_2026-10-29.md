## 변경

| 이전 상단 메뉴 | 새 구조 |
|---|---|
| 학습 경로 | 학습관 → 추천 커리큘럼 |

- SiteNavigation 컴포넌트에서 상위 메뉴와 하위 링크를 표시한다. 상위 메뉴는 페이지가 아닌 펼침 버튼이며 한 번에 하나만 열린다. 현재 하위 페이지의 상위 메뉴와 해당 링크를 강조한다.
- 클릭·Enter/Space로 열기, Tab으로 링크 이동, Escape로 닫기와 상위 버튼 초점 복귀를 제공한다. 메뉴 밖 클릭·초점 이동·페이지 이동으로 닫는다. 호버를 필수로 하지 않아 터치에서도 같은 동작이다.
- 기존 /path·/certs·/updates·/calendar 주소, 홈 로고, 개발자 메뉴 숨김, 개인화 제외를 유지한다.
- 추천 커리큘럼 명칭을 제목·홈 이동 버튼·교육·인증의 돌아가기 링크에도 반영했다. 본문의 일반 표현이나 공식 자료의 학습 경로 명칭은 바꾸지 않았다.
- Root·i18n과 README·PLAN·TERMINOLOGY를 갱신했다. 이전 달력 변경은 별도 커밋 265c41d에 보존했다.

## 검증

- 기존 회귀 검사 90건, 타입 검사·selfcheck·빌드 통과. Tailwind sourcemap 경고는 기존과 같고 빌드는 성공했다.
- 실제 브라우저에서 학습관 두 링크와 정보관 두 링크 이동, 이동 후 닫힘, Escape 초점 복귀·Tab 링크 이동·바깥 클릭 닫힘을 확인했다.
- 320px 화면의 문서 폭 312px, 하위 메뉴 범위 x=16~296으로 가로 넘침 없음. 라이트·다크 배경/문구·투명 로고 및 오류 로그 0건을 확인했다. 실기기·스크린리더 검증이나 적합성 인증은 아니다.
