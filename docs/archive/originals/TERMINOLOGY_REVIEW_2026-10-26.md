# 전체 화면 용어 점검·정비 결과

기준일: 2026-10-26. 사용자 요청은 일관성·명확성·실제 범위에 맞는 명칭과 재사용 가능한 선정 가이드다. 이번 작업은 용어와 주소 호환 정비이며 수집 범위·분류 로직·개인화·SNS 기능을 확대하지 않는다.

홈·공통 메뉴·학습 경로·교육·인증·소식 카드·상태 및 오류·캘린더·설정·운영 진단·약관·개인정보 안내·HTML 설명을 함께 점검했다. 논문 카드의 중복 ‘논문 원문’ 표현을 제거하고 예상 읽기 시간이 화면에 표시된 제목·설명문 기준임을 명시했다. 원문 전체의 읽기 시간으로 보장하지 않는다.

## 보존 범위

수집 출처 목록·RSS URL·분류 키·JSON 스키마·자료 건수·원문 제목·기관의 공식 인증명·비용 근거·자동 수집 주기·워크플로 권한은 보존한다. `News Refresh`와 `news.json` 등 운영 식별자는 표시 이름과 구분한다. 내부 화면 파일은 Research에서 Updates로 변경하고 새로운 내부 링크는 `/updates`를 사용한다. 날짜가 붙은 기존 작업 보고서는 당시 상태의 이력으로 보존한다.

기업·CEO SNS는 계획만 유지한다. 이번 명칭 정리가 해당 기능의 구현을 의미하지 않는다. 국내 공식 행사 출처 확보·미확인 교육 조건·실기기/스크린리더 검증·실제 문의 주소는 기존 남은 과제다.

## 이후 참고

표준 메뉴·주소, 혼합 자료와 기사 구분, 출처 지역·제공처·출처 유형 구분, 교육·일정·공통 표현, 코드 호환 및 신규 용어 검토 절차는 [TERMINOLOGY.md](./TERMINOLOGY.md)를 따른다. 현재 README·PLAN·CHECKLIST·AGENTS·AUTOMATION·SOURCE_REGISTRY에서 이 기준으로 연결한다.

## 검증

- 회귀 검사 73건·TypeScript 검사·selfcheck·제품 빌드 통과. 기존 Tailwind sourcemap 경고가 남으며 빌드 실패는 아니다.
- 개발 서버에서 `/research?source=legacy#main-content` 및 `/research/?compat=1#main-content`가 각각 검색 문자열·해시를 유지한 `/updates`로 이동했다.
- 홈 → 이전 주소 → 새 주소 → 뒤로 가기에서 홈으로 돌아왔다. 이전 주소로 돌아가는 순환이 없었다.
- 메뉴·제목·출처 지역·자료 언어·제공처·모델 유형·출처 유형·교육 유형·화면 테마를 브라우저에서 확인했다.
- 320px에서 AI 소식·교육·인증·캘린더의 본문 가로 넘침이 없었다(문서 너비 312px). 캘린더 기본 ‘국내·온라인’ 선택을 확인하고 검사 후 임시 화면 크기를 해제했다.
- 브라우저 오류 로그는 0건이었다. 이번 범위의 문구 정비에 별도 테스트를 추가하지 않고 기존 검사와 주소·화면 동작으로 확인했다. 실기기·스크린리더 검증을 뜻하지 않는다.
