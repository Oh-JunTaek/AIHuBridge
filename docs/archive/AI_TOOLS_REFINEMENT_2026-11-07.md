# AI 도구함 카드와 자료 보완

2026-11-07 사용자 요청에 따른 로컬 작업 결과다. 최신 범위는 [PLAN](../../PLAN.md), 공식 출처는 [SOURCE_REGISTRY](../standards/SOURCE_REGISTRY.md)를 따른다.

## 카드

- 카드의 둥근 모서리와 2열·모바일 1열 구성은 유지하고, 상단의 무료 조건 배지를 ‘자료 기반 학습’, ‘논문 탐색’처럼 도구의 핵심 역할로 변경했다.
- 기존 활용 설명을 연한 배경의 독립 영역으로 강조하고 도구별 기능을 작은 원형 표식이 있는 태그로 표시한다. 기능 태그의 단어도 검색할 수 있다.
- ‘무료 조건 확인’ 링크와 화면의 확인일을 제거했다. ‘도구 열기’의 표시 문구는 ‘활용해보기’로 변경하고, 보조 접근성 이름에는 도구명과 새 탭 열림을 유지한다.
- 무료 사용 한도·계정·상업적 이용처럼 선택에 영향을 주는 제한은 카드에 간단히 남긴다. 무료 조건의 공식 근거 URL과 실제 확인일은 데이터와 출처 관리표에 남겨 수동으로 재검토한다.
- 기업 로고는 사용하지 않았다. GitHub의 공식 브랜드 기준에서 허가 없는 사용과 변경을 제한하고, 다른 제품별 연한 배경 사용 허가도 확인되지 않았다. 원형 표식은 자체 일반 기호다.

## 자료 확대

기존 6개에 한국어 음성 기록 ‘클로바노트’, 논문 탐색 ‘Elicit’, 개념 시각화 ‘Napkin AI’, 음성 생성·기록 ‘ElevenLabs’를 더해 총 10개를 제공한다. ‘음성·회의’와 ‘시각화’ 필터를 추가했다. 무료 범위·제한은 각 제공처의 2026-11-07 안내를 확인했다. Gamma는 무료 AI 크레딧이 자동 갱신되지 않는다는 [공식 안내](https://help.gamma.app/en/articles/7834324-how-do-credits-work-in-gamma)가 있어 지속적으로 무료 사용하기에 적합하다고 단정하지 않고 이번 목록에서 제외했다.

## 검증

- 기존 전체 단위 검사 117건 중 116건 통과·1건 건너뜀(Windows 기본 비활성화된 실제 Git 데이터 브랜치 복원 검사). lint·selfcheck·빌드 통과, 기존 Tailwind 소스맵·번들 크기 경고가 남는다.
- Chrome 대체 설정의 도구함 PC·모바일 회귀 검사 2건 통과. 음성·회의 2건과 ‘한국어 요약’ 검색 1건, 초기화, 공식 도구 링크를 확인했다. 기본 Playwright 브라우저는 설치되어 있지 않다.
- 브라우저에서 320px 화면 폭에 문서 폭 312px, 카드·필터 배치를 확인했다. 실기기·스크린리더 검증은 수행하지 않았다. [카드 화면](../../artifacts/ai-tools-refined-2026-11-07.png).
- 로컬 커밋까지 진행하며 원격 푸시·배포는 포함하지 않는다.
