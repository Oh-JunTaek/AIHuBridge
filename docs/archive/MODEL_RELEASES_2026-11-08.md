# 모델 소식 신규 출시 중심 정비

2026-11-08 사용자 요청에 따른 로컬 변경이다. 모델 소식은 제목에 AI 모델 또는 확인된 모델명과 출시·발표 표현이 함께 있는 자료를 규칙으로 선별한다. 수익·비즈니스 모델, 단순 활용·비교, 가격, 출시 예정·취소, 서비스 기능 발표의 일부 표현은 제외한다. 기존 전체 소식과 자료 보관 기간은 유지한다. 자동 규칙이므로 출시 발표 누락이나 오분류 가능성이 있으며 원문 검증과 다르다.

언어·음성·이미지·영상·멀티모달·코딩·로봇·임베딩·시계열에 더해 추론·판단 유형을 추가했다. 한국어·영어 Google 뉴스 모델 출시 RSS를 추가하고 출시 제목만 수집한다. 출처 및 조건은 출처 관리표를 따른다. 한 행사에 대한 여러 기사를 동일 모델로 합치지 않으며 URL 중복만 제거한다.

실제 공개 피드 저장 없는 시험에서 한국어 20건·영어 20건, URL 중복 제거 후 40건을 확인했다. 회당 한도에 도달한 표본이며 정확성 전수 검증이나 운영 데이터 갱신은 아니다. 단위 검사 118건 통과·1건 건너뜀, lint·selfcheck·빌드 통과, PC·모바일 모델 소식 회귀 검사 2건 통과. 기존 빌드 크기·소스맵 경고가 남는다. 원격 푸시·배포·정기 수집 반영은 수행하지 않았다.
