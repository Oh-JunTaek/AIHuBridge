# 무료 AI 기초 강의 확충과 구현 계획 점검

> 이 문서는 과거 기록이며 현재 지시가 아니다. 현행 기준은 [AGENTS](../../AGENTS.md)·[PLAN](../../PLAN.md)·[문서 우선순위](../standards/DOCUMENTATION.md)를 따른다. 완료·미완료·수치·Git 상태는 작성 당시 기준이다.

기준일: 2026-10-26. 작업 이력이다. 현재 범위는 AGENTS.md → PLAN.md → AUTOMATION.md를 우선한다.

## 반영 결과

부스트코스 7개와 성균관대 SKKU Online 2개를 추가했다. 교육·인증 자료는 총 24개이며 이 중 학습 과정은 17개다. 기존 자료를 유지하고 새 기초 과정을 목록 앞에 배치했다. 학습 경로는 기초 쌓기 5개를 포함한 4단계·16개 항목으로 확장했다.

학습 경로에 프로그래밍·데이터, AI 수학 분야를 추가했다. 새 기초 강의의 소요 시간을 임의로 만들지 않고 자율 학습으로 안내한다. 단계는 탐색 안내이며 개인 체크·진도·추천·이력은 추가하지 않았다.

## 추가 데이터 규칙

- 수료증 미발급은 credentialFee.status = not-offered로 표시한다. 미확인·유료·무료 발급과 구분한다. 미발급에 금액을 붙이거나 학습 비용을 미발급으로 지정하는 자료는 검사에서 거부한다.
- availableUntil은 한국 기관이 명시한 수강·학습 종료 날짜다. 한국시간 종료일의 마지막 순간까지 포함하고 이후 공개 교육 목록에서 제외한다. 교육 화면이 열려 있으면 1분 간격으로 다시 평가한다.
- availableUntil이 없는 상시 과정에 종료일을 추정하지 않는다. 형식 오류·불가능한 날짜는 스키마 검사와 공개 목록에서 거부한다.
- 뉴스·행사 수집 로직이나 워크플로는 변경하지 않았다. 무료 강의는 공식 페이지를 검토한 정적 안내이며 자동 행사 수집 출처를 추가한 것이 아니다.

## 구현 계획은 전부 끝났는가

**현재 PLAN 기준으로 전체 완료가 아니다.** 완료 기능과 아래 남은 항목을 분리한다. 개인화는 미완료가 아니라 현재 버전 제외 결정이다.

| 구분 | 상태 |
|---|---|
| 공개 뉴스·캘린더와 필터, 월간 달력, 오류/중복/마감 처리 | 구현 완료 |
| 하루 2회 수집 → 봇 커밋 → 성공 후 자동 배포 | 구현·실운영 검증 완료, 지속 운영 대상 |
| 비개인화 학습 경로·교육 탐색, 비용/근거 모델, 무료 기초 강의 | 구현 완료 |
| 개발자 메뉴 제거·투명 로고·반응형·키보드 개선 | 구현 및 브라우저 검증 완료 |
| 국내 공식 행사 자동 수집 출처 추가 | 허가·정책·명시적 일정 확인을 충족한 신규 출처 확보가 남음 |
| 미확인 수료증·평가 비용과 교육 조건 | 공식 근거를 더 확인해야 함. 확인 전 미확인 표시 유지 |
| 실기기·스크린리더 및 정식 접근성 적합성 | 미검증 |
| 공개 문의 주소 | 사용자 결정으로 추후 작성. eunmastudio만 표기 |
| 로그인·북마크·개인 기록·추천·알림 | 현재 버전 제외, 복구하지 않음 |

국내 정적 강의를 추가한 것으로 국내 행사 자동 수집 과제를 완료 처리하지 않는다. 개발 기능과 지속적인 출처 검증·실기기 검증을 같은 완료 항목으로 합치지 않는다.

## 검증

- npm test 57건, npm run lint, npm run selfcheck, npm run build 통과. 기존 Tailwind sourcemap 경고는 남는다.
- npm run dev 및 실제 브라우저 확인. 교육 전체 24개·학습 참조 16개 검사.
- 부스트코스 검색+학습 무료 필터 7개, 같은 검색+수료증 무료 0개. 미발급 과정 1개와 미발급 표시 확인. 성균관대 검색 2개 및 각각의 종료일 확인.
- 기초 경로와 AI 수학 필터 확인. 320px의 경로·교육 페이지에서 가로 넘침 없음.
- 종료일 마지막 밀리초·이후 제외와 불가능한 날짜 거부를 회귀 검사했다.
