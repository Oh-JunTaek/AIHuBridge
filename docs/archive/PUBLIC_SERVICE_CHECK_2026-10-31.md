# 공개 서비스 체크리스트 점검

2026-10-31 사용자 제공 이미지의 20개 항목을 현재 코드와 운영 범위에 대조한 기록이다. 법률 적합성이나 모든 외부 자료의 권리를 보증하는 감사는 아니다.

| 항목 | 확인 결과와 조치 |
|---|---|
| 1 개인정보 안내 | 기존 안내에 문의 메일의 전달 경로와 개인정보 열람·정정·삭제 요청 연락처를 보강. 실제 보관·삭제 기준은 운영자가 정해야 한다. |
| 2 이용약관 | 공개 정보 서비스의 이용안내·약관과 링크가 있다. 법률 검토 완료를 뜻하지 않는다. |
| 3 환불 | 사이트에 결제·판매 기능이 없다. 연결된 외부 과정의 비용과 환불은 제공처 조건을 따른다. |
| 4 쿠키 정책 | 앱 코드에 별도 쿠키 설정이 없는 점을 안내. GitHub 등 외부 서비스의 실제 처리는 각 제공처 정책을 참고한다. |
| 5 쿠키 동의 배너 | 앱에서 자체 광고·분석 쿠키를 설정하는 코드가 발견되지 않아 배너를 추가하지 않았다. 외부 서비스의 모든 쿠키를 검사한 결론은 아니다. |
| 6 양식 동의 | 가입·개인정보 입력 양식은 없고 문의는 사용자의 메일 앱을 통한다. 향후 입력 기능 추가 시 다시 검토한다. |
| 7 수집 최소화 | 앱은 로그인이나 개인 학습 기록을 제공하지 않는다. 문의 이메일과 호스팅 사업자 네트워크 기록은 별도로 존재할 수 있다. |
| 8 외부 SDK | 패키지와 코드의 외부 요청을 확인. GitHub Pages·Google Fonts, SNS 화면의 Bluesky 직접 요청을 기존 개인정보 안내에 기재한다. 모든 의존성의 공급망 감사를 뜻하지 않는다. |
| 9 원치 않는 선택 유도 | 주요 링크는 목적지와 버튼 이름을 함께 제공한다. 모든 사용성 흐름의 전수 감사는 아니다. |
| 10 숨겨진 요금 | 서비스 자체 결제 기능이 없다. 외부 교육·응시의 비용과 조건은 제공처를 확인하도록 안내한다. |
| 11 가짜 후기 | 사용자 후기·평점 기능이 없다. |
| 12 근거 없는 주장 | 시험·훈련 등의 원문 링크와 확인일을 제공하며 미확인 값을 추정하지 않는 기존 기준을 유지한다. 외부 자료 전체의 최신성을 이번에 재검증한 것은 아니다. |
| 13 이미지 대체 텍스트 | 홈·자격증·자료실·수료 과정 이미지의 alt 속성을 브라우저 검사한다. 장식 그림은 빈 대체 텍스트 또는 보조기기 비노출을 사용한다. |
| 14 색상 대비 | 기존 감사에서 일부 보조 텍스트를 보강했다. 전 화면·상태의 대비 검사는 아직 남았다. |
| 15 키보드 | 기존 건너뛰기 링크·대화상자 Escape·포커스 복원·캐러셀 방향키를 브라우저 검사한다. 실제 스크린리더·모든 키보드 조합 검증은 남았다. |
| 16 운영자 정보 | 사이트에 운영명과 이메일이 있다. 사업자 등록 여부 및 추가로 필요한 표시는 확인하지 못했다. |
| 17 아동 정보 | 사이트에 계정 생성이나 아동 정보를 입력하는 양식은 없다. 문의 메일과 호스팅 정보는 별도로 처리될 수 있다. |
| 18 수신 거부 | 서비스에서 뉴스레터나 광고성 메일을 발송하는 기능이 없다. 추후 도입 시 다시 검토한다. |
| 19 이미지·글꼴 권리 | 사용 허락이 확인되지 않은 기관 로고와 홈 AI 기업 로고 표시를 자체 도형으로 대체했다. 다른 이미지와 글꼴·패키지의 권리 전수 확인은 남았다. 기존 원본 파일을 다시 사용할 때에도 권리 확인이 필요하다. |
| 20 개인정보 삭제 요청 | 문의 이메일로 삭제 요청을 보낼 수 있음을 안내한다. 자동 삭제 기능은 없으며 실제 보관·처리 기준은 미정이다. |

참고: [개인정보 보호법 제30조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025127663), [GitHub Pages 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages), [GitHub 개인정보 안내](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement), [Bluesky 네트워크 개인정보 안내](https://bsky.social/about/support/network-services-privacy-policy). 적용 의무·개별 사안은 서비스 실제 운영 방식에 따라 확인해야 한다.
