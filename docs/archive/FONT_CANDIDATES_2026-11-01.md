# AI HuBridge 글꼴 후보 — 2026-11-01

선택 전 조사다. 실제 서비스 글꼴을 변경하지 않았다. 아래 후보는 공식 배포본의 SIL OFL 1.1을 확인했으며 웹사이트와 상업적 서비스에 쓸 수 있다. 파일을 서비스와 함께 재배포할 때 저작권·라이선스 고지를 포함하고, 글꼴 파일 단독 판매와 수정본의 예약된 글꼴 이름 사용 제한을 확인한다.

| 후보 | 디자인 판단 | 공식 배포·라이선스 |
|---|---|---|
| Pretendard | 중립적이고 간결하다. 한글·영문·숫자가 함께 나오는 카드와 긴 목록에 무난한 1순위 | [제작자 안내와 표본](https://github.com/orioncactus/pretendard), [라이선스](https://github.com/orioncactus/pretendard/blob/main/packages/pretendard/dist/LICENSE.txt) |
| SUIT | 둥근 인상이 조금 더 친근해 부드러운 학습관 분위기에 어울릴 후보 | [제작자 안내](https://github.com/sun-typeface/SUIT), [라이선스](https://github.com/sun-typeface/SUIT/blob/main/LICENSE) |
| IBM Plex Sans KR | 또렷하고 기술적인 인상으로 정보관의 데이터·영문 표기에 어울릴 후보 | [IBM 공식 저장소](https://github.com/IBM/plex), [한국어 글꼴 라이선스](https://github.com/IBM/plex/blob/master/packages/plex-sans-kr/LICENSE.txt) |
| Noto Sans KR | 다양한 언어를 폭넓게 고려한 안정적인 선택. 서비스의 많은 외국어 이름에 적합 | [Noto 사용·라이선스 안내](https://github.com/notofonts/noto-docs/blob/main/docs/website/use.md), [Google Fonts 표본](https://fonts.google.com/noto/specimen/Noto+Sans+KR) |

실제 화면에서의 인상과 읽기 편함은 글자 크기·두께·운영체제에 따라 달라진다. 후보를 선택하면 우리 서비스의 홈 제목, 긴 뉴스 제목, 자격 메타데이터를 PC와 모바일에서 비교한 다음 전체 적용한다. 현재 Google Fonts에 요청하는 Pretendard 주소는 400 오류로, 사용 중인 브라우저에서는 설치된 글꼴이나 시스템 대체 글꼴이 보일 수 있다. 최종 선택 전에는 해당 주소를 임의로 바꾸지 않는다.
