# AI HuBridge 사용자 관점 점검

점검일: 2026-11-09 (한국시간). 공개 사이트를 실제로 열어 홈·대시보드, AI 소식·모델·논문, AI 캘린더, 기업 SNS, 추천 커리큘럼, 학습 자료실·수료 강의·자격증, AI 도구함, 채용관을 표본 탐색하고 코드·계획·GitHub Actions 기록과 대조했다. PC 브라우저 중심의 정성 평가이며 전수 조사, 실기기 모바일·실제 스크린리더 검사 또는 콘텐츠의 진실성 검증은 아니다. 개선안은 제안이며 사용자 확정 정책이 아니다.

## 종합

- 공간별 그림과 색감이 통일되어 있고, 학습 목적을 선택해 단계별 자료로 이동하는 구조는 초보자의 출발점을 제공한다. 무료 학습과 수료 비용을 구분하고 행사·자격의 미확인 정보를 단정하지 않는 점도 장점이다.
- 가장 큰 병목은 화면 장식보다 **수집된 자료를 고르고 판단하는 데 드는 노력**이다. 유사 기사 반복, 발표 외 기사의 모델 분류, 국내에서 실질적으로 참여하기 어려울 수 있는 온라인 일정, 정보가 거의 없는 신청 마감이 한 번에 보였다.
- 공개 사이트에서 마지막 수집 시각은 소식 11월 9일 10:17:32, 일정 10:18:00이었다. 최신 수집 시각은 수집 경로 전체의 성공이나 자료의 완전성을 보증하지 않는다.

## 우선 검토 제안

### 1. 관련 기사 묶기와 모델 발표 판별

- 관찰: AI 소식의 최근 7일 629건 중 첫 화면에서 LG K-엑사원 2.5의 API 공개를 다룬 여러 언론 기사가 연속으로 보였다. 모델 소식 50건의 처음 24개에도 카카오 카나나 모델을 다룬 여러 보도가 반복됐다. 서로 다른 출처의 보도이므로 단순 중복 삭제와는 구분해야 한다.
- 관찰: 모델 소식에는 기존 모델의 보안 성과를 다룬 기사, Qwen 4 출시일 전망 기사도 섞였다. 반대로 모델과 같은 이름을 포함한 내용이 동일한 분야 태그를 갖지 않는 예도 있었다. `src/lib/news-facets.mjs`는 제목·본문 키워드를 기준으로 분류하므로 이런 오류와 누락이 가능하다.
- 제안: 원문을 삭제하지 않고 동일 발표 후보를 묶어 대표 자료와 다른 출처를 펼쳐 보여주는 실험을 한다. 공식 발표 원문이 확인되면 우선 연결하고, 기출시·전망·기능 추가는 근거가 불명확하면 자동 단정하지 않는다. 국내 모델명·발표 표현에 대한 정답 표본을 만들고 누락과 오분류를 함께 측정한다. LLM 도입은 별도 논의다.

### 2. 국내 참가에 유용한 캘린더 확대

- 관찰: 공개 기본 화면에서 56건 중 온라인이 52건이었고, 신청 마감일은 확인된 항목이 없다는 안내가 보였다. Intel·NVIDIA 서울 행사는 찾을 수 있었으나 해외 영어권 커뮤니티 행사가 다수를 차지했다. 온라인 여부는 한국 거주자의 자격·시차·언어까지 확인했다는 뜻이 아니다.
- 제안: 국내 행사 주최사의 공식 행사 페이지와 공개 행사 플랫폼을 이용 조건·수집 가능성 확인 후 추가하고, 실제 장소·온라인 접근 근거를 수집 시 검증한다. 언어·한국시간·신청 기한이 원문에 있을 때만 구조화하고 미확인은 유지한다. 해외 온라인을 일괄 삭제하거나 장소·시간을 추정하지 않는다. 국내 자동 발견의 미완료는 PLAN의 기존 항목과 연결한다.
- 검증: 국내 공식 행사 표본을 정해 발견 여부, 국내/온라인 근거, 중복, 신청 마감 확보율을 측정하고 출처 실패와 정상 0건을 구별한다.

### 3. 논문의 탐색 가능성과 가독성

- 관찰: 연구·논문 필터에서 최근 7일 120건이 보였고 arXiv 원문 링크를 제공한다. 카드에는 `arXiv:... Announce Type: ... Abstract:` 같은 피드 머리말, 중간에서 잘린 영문 초록, `$...$` 수식 표기가 그대로 노출됐다. 일부 수학·응용 논문은 제목만으로 일반 방문자가 관련성을 파악하기 어렵다.
- 제안: 피드의 기술 머리말을 안전하게 제거하고 문장 경계와 원문의 수식 표기를 검토한다. 논문·연구 보도·사전 공개 논문 등 출처 성격을 명확히 보여주고, 관심 분야 태그가 없는 경우에는 억지로 분류하지 않는다. 획기성 또는 중요도는 근거 없이 표시하지 않는다. 번역·LLM 요약 도입은 별도 승인과 방법 논의가 필요하다.

### 4. 수료 강의의 카드 설명과 콘텐츠 폭

- 관찰: 수료증 취득 강의의 공개 목록은 5개였다. `Google AI Essentials` 카드에는 학습 주제 대신 미국·캐나다 가격 안내가, Hugging Face Agents 카드에는 계정·기록 조건이 주 설명처럼 노출됐다. 비용·수료 조건 구분은 유익하지만 무엇을 배우는지 먼저 알기 어렵다.
- 제안: 카드에는 학습 내용·대상·언어를 먼저, 수료증 비용과 조건은 별도 필드에 배치한다. 한국어 무료 학습·수료 가능 여부를 공식 근거와 함께 표본별로 다시 확인하고 후보를 늘린다. 무료 학습과 무료 수료증은 합치지 않는다.

### 5. 기업 SNS의 기대와 실제 범위

- 관찰: 직접 열었을 때 최근 7일 게시물은 0개로 표시됐다. 연결된 자동 피드는 Anthropic·Hugging Face·Mozilla.ai의 Bluesky/Mastodon 계정이며 OpenAI X·YouTube는 외부 링크다. 실패가 아닌 정상 빈 결과였는지 또는 해당 계정의 실제 게시 여부는 이 표본만으로 확인하지 못했다.
- 제안: 사용자에게 자동 수집되는 계정·플랫폼과 외부 링크만 제공하는 채널을 더 선명하게 구분하고, 계정별 정상 빈 결과·연결 실패·마지막 확인 시각을 구분한다. OpenAI·xAI 등 사용자가 원하는 범위는 제공처 정책과 API 접근 조건을 확인한 뒤 확장한다. X 게시물 수집 가능성을 가정하지 않는다.

### 6. 채용관 기대와 실제 내용

- 관찰: 채용관에는 4개 직무 소개, 고용24 링크, 확인 당시 훈련 예시 1건이 있었고 채용행사는 개별 정보 확인 중이었다. 현재 명칭과 소개는 방문자가 실제 채용공고 목록까지 기대하게 할 수 있다.
- 제안: 첫 화면에 현재 제공 범위(직무 안내·훈련 예시·공식 채용행사 연결)를 명확히 표시한다. 개별 행사·훈련 자동 갱신은 고용24 기존 장애와 데이터 이용 조건 검증을 먼저 해결한 후 추진한다. 신규 외부 저장소·유료 서비스는 별도 승인 대상이다.

### 7. 화면 밀도와 이동

- 관찰: 큰 상단 이미지와 긴 필터 패널은 공간의 분위기를 만들지만 실제 결과가 첫 화면 아래로 밀린다. 국내 출처 선택은 AI 소식 ‘상세 조건’에 있어 처음 방문한 사용자가 놓치기 쉽다. 달력 날짜 선택 즉시 팝업, 도구 활용 상자 통합은 공개 페이지에서 확인했다.
- 관찰: AI 도구함은 직접 주소와 학습관에서 이용할 수 있으나 홈 전시 공간 목록과 대시보드 빠른 이동에는 나타나지 않아 다른 주요 기능보다 발견하기 어렵다. 학습 자료실에는 38건이 있고 부스트코스 한국어 강의도 확인됐다.
- 제안: PC·모바일 실제 화면별로 첫 결과까지의 거리, 주요 필터 발견 가능성, 터치 영역과 글자 대비를 측정한다. 국내/전체 선택은 관심 분야와 겹치지 않도록 상위에 노출하는 안을 검토한다. 기존 정보와 정책을 없애기보다 짧은 설명과 필요 시 펼침으로 배치한다.

### 8. 갱신의 신뢰성과 운영

- 확인: GitHub Actions의 11월 7~9일 예약 수집과 후속 배포가 각각 성공했다. [11월 9일 예약 실행](https://github.com/Oh-JunTaek/AIHuBridge/actions/runs/42544770071)은 10:17 KST에 시작했고, [후속 배포](https://github.com/Oh-JunTaek/AIHuBridge/actions/runs/42544867923)도 성공했다. cron은 07:00 KST로 설정돼 있으나 실제 시작 시각이 그보다 늦었다. 원인은 이 점검으로 확정하지 않았다.
- 확인: 커밋 `b6ace5b`의 [공개 배포](https://github.com/Oh-JunTaek/AIHuBridge/actions/runs/42638083678)가 성공해 이전 로컬 변경도 공개됐다.
- 제안: 방문자에게 ‘매일 오전 7시 예정, 실제 갱신 시각은 달라질 수 있음’을 안내하고 출처별 성공·실패·마지막 성공 시각과 오래된 자료 상태를 운영자가 확인할 수 있게 한다. 전체 워크플로 성공을 모든 출처 성공으로 표시하지 않는다.

## 권장 작업 순서

1. 동일 발표 묶음과 모델 발표 표본 평가: 대상과 기준을 정하고 오분류·누락을 수치화한다.
2. 국내 공식 행사 자동 발견: 출처 접근 조건·실제 표본·마감/언어 정보를 검증하고 실패 시 안전하게 보존한다.
3. 수료 강의 카드의 내용 우선 정리와 한국어 자료 보강: 공식 근거와 비용·수료 조건을 재확인한다.
4. 논문 카드에서 기술 머리말과 잘린 문장 처리: 원문 의미를 바꾸지 않고 서식을 개선한다.
5. SNS 빈 상태·출처별 갱신 상태 개선, 이후 제공처별 확장 가능성을 별도 조사한다.
6. 작은 화면의 결과 도달·필터 발견과 실제 스크린리더·모바일 기기 검증을 진행한다.

각 항목은 별도 작업으로 범위·표본·검증을 확정한다. 현재 점검은 기능 구현이나 새 외부 서비스 도입 승인이 아니다.
