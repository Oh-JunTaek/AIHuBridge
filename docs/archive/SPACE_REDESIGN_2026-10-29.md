# 정보관·학습관 화면 재구성 (2026-10-29)

- 사용자가 기존 구조의 전면 재설계를 허용함에 따라 정보관과 학습관의 네 화면을 재배치했다. 홈의 전시관 시각 자산과 청색·황금색 계열은 이어간다.
- AI 소식은 분야·출처·상세 조건을 왼쪽 탐색 패널에 배치하고 결과를 읽기 쉬운 단일 열로 구성했다. 모델 등 기존 세부 필터와 24건 더 보기는 유지한다.
- 추천 커리큘럼은 난이도·분야 선택과 단계별 결과를 나누고 단계 사이에 길을 표현했다. 교육·인증은 유형과 탐색 조건을 자료실 패널에 두고 결과를 별도로 표시한다. 모바일에는 결과 바로 보기 링크를 제공한다.
- AI 캘린더는 달력을 조건 영역 앞에 두고 날짜·조건·결과 이동 링크를 제공한다. 달력/목록 전환과 조건, 지역 기본값, 날짜 선택을 보존한다. 캘린더의 헤더와 본문 max-w-4xl은 유지한다.
- 기능 데이터, 데이터 수집, 저장, 주소, 네트워크와 접근 권한 정책을 변경하지 않았다. 대시보드·설정·홈의 개별 구조 재설계는 이번 범위에 포함하지 않았다.
- 로컬 브라우저: 소식 모델 분야 선택 시 결과 89→28건 및 상세 필터, 교육 유형 선택 시 17→5건, 캘린더 날짜 선택과 목록 전환을 확인했다. 데스크톱 네 화면과 320px 소식 화면, 라이트·다크 화면 일부를 확인했다. 실기기·스크린리더 및 모든 화면 조합은 미검증이다.
