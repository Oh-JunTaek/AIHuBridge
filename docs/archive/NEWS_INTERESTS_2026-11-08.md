# AI 소식 관심 분야 2차 필터

2026-11-08 사용자 확인에 따른 로컬 변경이다. 상위 소식 분류와 독립적으로 언어·LLM, 이미지, 영상, 음성·음악, 멀티모달, 추론·판단, 에이전트·로봇, 코딩, 검색·임베딩, 예측·시계열, 안전·보안을 단일 선택해 함께 적용한다. 기본값과 초기화는 전체다. 상위 분류를 바꿔도 선택한 관심 분야는 유지한다.

소식은 복수 태그를 가질 수 있으며 이미지·영상 두 분야를 가진 논문은 두 조건에서 각각 나온다. 제목·기존 설명과 일부 논문 코드를 이용해 브라우저에서 태그를 계산한다. 기존 JSON 수정, 외부 API·LLM, 개인화 저장은 없다. cs.CV는 이미지·영상 모두를 아우르므로 코드만으로 이미지나 영상으로 추정하지 않는다. 근거가 부족한 자료는 미분류이며 전체 보기에는 남는다. 키워드 방식은 오분류·누락이 가능하다.

현재 로컬 `public/data/news.json` 386건 중 268건은 선택한 관심 분야의 명시적 근거가 없어 미분류였다. 수집 시기·범위에 따른 표본이며 운영 자료의 분류율을 뜻하지 않는다.

2차 필터 변경 시 결과 카드가 짧은 간격으로 등장하고 모션 축소 설정에서는 즉시 나타난다. 단위 검사 120건 통과·1건 건너뜀, lint·selfcheck·빌드 통과. PC·모바일 브라우저 검사 4건 통과: 상위 분류와 조합, 이미지·영상 개별 노출, 선택 유지, 초기화, 화면 폭, 애니메이션·모션 축소. 실기기·스크린리더는 미검증이다. 기존 빌드 크기·소스맵 경고가 남는다. 원격 푸시·배포는 수행하지 않았다.
