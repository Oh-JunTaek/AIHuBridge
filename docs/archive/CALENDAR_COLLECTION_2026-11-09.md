# AI 행사 자동 수집 단계 개선

2026-11-09 사용자 요청에 따라 최종 화면 분류뿐 아니라 각 출처의 후보 수집 단계에서 국내 현장 또는 명시적 온라인 참가 가능성을 검사한다. 카카오 RSS 외 NAVER D2, AWS 한국 블로그, Microsoft 한국 소식의 공개 RSS를 하루 1회 기존 예약에 포함한다. AI 관련 행사·모집 근거와 명시적 신청 마감 또는 개최일이 있어야 한다. RSS에 `진행 방식: 온라인` 또는 오프라인 방식과 국내 `장소:`가 명시된 경우만 허용하며 참가 방식의 추측, 온라인 신청을 온라인 행사로 오인, 해외 현장과 애매한 혼합 표기는 제외한다. 개최 날짜만 있는 경우 시각을 생성하지 않는다.

Google 공식 공개 일정의 `VIRTUAL`, `IN_PERSON`, `HYBRID`를 분리 처리한다. HYBRID는 온라인 참가가 명시된 것으로 수집하고 `attendanceMode: hybrid`를 보존해 화면에 ‘온라인·현장 병행’으로 표시한다. 온라인 참여여도 국가별 제한이나 참가 자격은 별도로 원문 확인이 필요하다. 출처에서 기존 온라인 행사를 해외 현장 또는 확인 불가로 바꾸면 예전 온라인 상태를 다시 공개하지 않는다. 출처 장애나 목록에서 항목이 사라진 경우에는 기존 유효 자료를 보관 정책에 따라 유지한다. 취소·연기 공지 보존도 기존 원칙을 따른다.

실제 공개 자료를 파일에 저장하지 않고 시험: 카카오 RSS 12건, NAVER D2 20건, AWS 한국 10건, Microsoft 한국 10건 수신했고 적격 행사 0건이었다. Google 공개 일정은 961건 중 보관 대상 118건을 수집했고 이 중 36건이 하이브리드였다. 지난 행사 보관을 포함한 실행 시점 표본이며 각각의 국가별 참가 자격을 검증한 수치가 아니다. 새 RSS가 모든 국내 기업 행사를 포함하거나 인텔·NVIDIA의 향후 행사를 자동 발견한다는 보장은 없으므로 국내 행사 출처 확대는 미완료로 유지한다.

검증: 단위 검사 125건 통과·1건 건너뜀, lint·selfcheck·빌드 및 PC·모바일 브라우저 검사 4건 통과. RSS 국내 현장·온라인·해외·미확인·국내 참가 불가·변경 후 기존 상태 제거와 Google 하이브리드, 장애 시 기존 자료 보존은 테스트 픽스처로 확인했다. 원격 GitHub Actions 예약 실행·실제 배포는 수행하지 않았다. 기존 번들 크기·소스맵 경고가 남는다.
