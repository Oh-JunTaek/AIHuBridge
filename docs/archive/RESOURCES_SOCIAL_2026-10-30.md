# 학습 자료실과 기업 SNS

## 구현 범위

- `/resources` 학습 자료실에서 기존 교육 과정·역량 평가와 OpenAI Academy, Claude Academy, Kaggle Pandas, Google 머신러닝 실습을 찾는다. 강의·실습·프로젝트·플랫폼·역량 평가 필터와 검색을 제공하며 한 자료는 여러 유형에 속할 수 있다. 수료관과 자격관을 구분한다.
- `/social`에서 Bluesky 공개 API를 브라우저가 직접 조회한다. Anthropic 공식, Hugging Face 공식, Thomas Wolf 개인 계정을 고정 DID로 식별한다. 기업·계정 유형·기간 필터, 제품·작성자·본문 검색, 실제 작성자와 재게시 여부, 원문 링크, 계정별 실패와 24건씩 이어보기를 제공한다. 게시물을 저장하지 않으며 한 계정의 최신 응답 최대 100건까지만 탐색한다. AI로 중요도나 예고·추측을 판정하지 않는다.
- 블루스카이의 민감 콘텐츠 라벨 및 `suppressedPostUris` 제외 목록을 반영한다. 운영자는 공개 이메일을 통해 받은 정정·삭제 신고를 처리해야 한다. 원문 삭제는 다음 조회에 반영되며 이미 열린 화면은 새로고침해야 한다.
- 홈 캐러셀에 기존에 빠진 대시보드와 학습 자료실·기업 SNS를 추가하고 수료관·자격관도 각각 다른 이미지를 사용한다. 지원하지 않는 개발 진단·법적 안내·이전 주소는 홍보 카드 대상에서 제외한다. 접근 메뉴·대시보드 빠른 링크와 문의 주소를 갱신했다.
- 사용자가 제공한 그림을 참조해 내장 이미지 생성기로 5개 삽화를 제작했다. 프롬프트는 각각 학습 책상·코드, 수료증과 학습자, 전문 자격시험 책상, 전시관 대시보드, SNS 말풍선을 주제로 하며 푸른색·아이보리·금색과 텍스트 없는 가로 구성을 요청했다. 결과물은 `src/assets/exhibit-{resources,completion,qualifications,dashboard,social}.png`에 저장했다.

## 검증과 한계

- Bluesky 실 API 검증에서 Anthropic 0건, Hugging Face 공식 98건, Thomas Wolf 100건이 반환되었다. 실제 게시물은 시점에 따라 바뀌며 0건은 오류와 구분한다. 관계자 게시물과 재게시를 공식 입장으로 취급하지 않는다.
- 로컬 브라우저에서 자료실 23개 자료, 실습 필터 4개, SNS 실제 게시물과 카드 화면을 확인했다. 모바일 실기기는 검증하지 않았다.
- `npm test`, `npm run lint`, `npm run selfcheck`, `npm run build`를 실행했다. 빌드에 기존 Tailwind 소스맵 경고가 있다.
- 다른 기업·관계자·플랫폼은 아직 포함하지 않았다. X 등 비지원 플랫폼은 계정 진위·API 이용 조건과 비용 확인 후 별도 확장한다. 주제별 추천 커리큘럼 재구성도 남아 있다. 원격 배포는 수행하지 않았다.
