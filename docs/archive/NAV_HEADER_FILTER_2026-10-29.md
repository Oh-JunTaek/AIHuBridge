# 메뉴와 배너 및 필터 정리

- 상단 메뉴의 점을 없애고 마우스 오버와 키보드 초점으로 하위 메뉴를 연다. 터치 화면에는 별도 메뉴 버튼을 표시한다. 상위 메뉴 링크는 기존 첫 하위 페이지로 이동한다.
- 대시보드, 정보관, 학습관의 상단 배너 폭과 기본 높이 및 상단 여백을 맞췄다. 캘린더는 이전 max-w-4xl에서 헤더·본문 모두 max-w-6xl로 조정했다. 좁은 화면에서 콘텐츠가 늘어나면 배너도 늘어난다.
- 탐색 패널의 분류 버튼을 작은 8px 곡률로 정리했다. 선택 상태와 필터 동작은 유지한다.
- 검증: 로컬 브라우저 반응형 화면, 메뉴·필터 동작, 타입 검사, 테스트, 자체 점검 및 빌드를 확인했다. 실제 모바일 기기와 스크린리더는 별도 검증하지 않았다.
