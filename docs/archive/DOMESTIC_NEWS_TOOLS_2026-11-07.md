# 한국 관련 AI 소식과 AI 도구함

2026-11-07 사용자 요청에 따라 소식 수집과 학습관 도구 탐색을 확장했다. 현재 범위는 [PLAN](../../PLAN.md), 출처와 이용 조건은 [SOURCE_REGISTRY](../standards/SOURCE_REGISTRY.md)를 따른다.

## 한국 관련 소식

- 기존 AI 한국어 검색과 별개로 한국·국내·네이버·카카오·삼성·업스테이지 키워드 검색을 추가했다. 제목의 매체명은 검색 판정에서 제외하고 제목에 AI와 국내 관련 단서가 함께 있어야 한다. 제목은 원문 그대로 보존한다.
- 국내 기업 카카오의 공식 기술 블로그 RSS를 추가하고 AI 관련 항목만 제목·날짜·링크로 수집한다. 국내 기업 6곳과 HyperCLOVA·Kanana 모델명 규칙을 추가했다. 사람이 선정한 키워드 분류는 오인·누락될 수 있으며 AI 모델이나 기업의 공식 입장으로 단정하지 않는다.
- URL 중복·발행일·보관 정책은 기존 로직을 유지한다. 한국어판 Google 검색 결과는 한국 관련 언급을 뜻하며 개별 언론사 국적이나 발생 국가를 보증하지 않는다.
- 실제 1회 읽기 전용 시험: 기존 Google 한국판 20건, 새 한국 검색 20건, 카카오 4건, URL 중복 제거 후 합계 43건. 새 검색에서 매체명 ‘한국경제’만으로 국내 관련이라고 판단하는 결함과 AI 없는 제목을 제외하는 검사를 추가했다. 운영 데이터는 갱신하지 않았다.

## AI 도구함

- 학습관 소개·메뉴에 `/tools`를 연결했다. NotebookLM, Perplexity, Consensus, DeepL, Canva, GitHub Copilot의 무료 이용 범위와 제한·계정 여부·확인일·공식 근거를 소개한다.
- 학습·자료, 논문·검색, 번역·글쓰기, 디자인, 코딩 필터와 검색·초기화를 제공한다. 로그인이나 기록 저장 없이 외부 도구의 공식 페이지로 이동한다. 무료 이용량과 기능은 변할 수 있고 일부는 사용량 제한이 있다.
- 제공처 근거는 출처 관리표와 각 카드 링크에 있다. 도구 사용의 충분성은 사람과 용도에 따라 다르므로 무제한 사용이나 모든 기능의 무료 제공은 보장하지 않는다.

## 검증과 배포 경계

- 전체 단위 검사 117건 중 116건 통과·1건 건너뜀. 건너뛴 검사는 Windows에서 기본 비활성화된 실제 Git 데이터 브랜치 복원 검사이며 이번 변경의 수집·표시 검사는 통과했다. 타입·selfcheck·빌드 통과, 기존 Tailwind 소스맵과 번들 크기 경고가 남는다.
- 기본 Playwright Chromium이 설치되지 않아 첫 브라우저 자동 검사는 실행 파일 누락으로 실패했다. 프로젝트의 `PLAYWRIGHT_CHROME=1` 대체 설정으로 기존 PC·모바일 검사 50건과 새 도구함 PC·모바일 검사 2건이 통과했다. 화면에서 6건 → 논문·검색 2건 → 초기화 6건과 검색 조합을 확인했다.
- 320px 브라우저 폭에서 문서 폭 312px을 확인했다. 실기기·스크린리더 검증은 수행하지 않았다. [화면 증거](../../artifacts/ai-tools-2026-11-07.png).
- 이번 소식 시험은 파일을 저장하지 않은 수집이며 실제 자동 데이터 브랜치·운영 JSON·배포를 갱신하지 않았다. 원격 실행·배포는 별도 사용자 승인 범위를 따른다.
