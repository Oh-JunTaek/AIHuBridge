# 과거 이력·현재 기준 충돌 정리 결과

> 과거 작업 결과다. 현재 기준은 [AGENTS](../../AGENTS.md)·[PLAN](../../PLAN.md)·[문서 우선순위](../standards/DOCUMENTATION.md)를 따른다. 검토일: 2026-10-28. 이번 작업은 로컬 검증·커밋 범위이며 새 변경을 원격에 배포하지 않는다.

## 사용자에게 확인한 결정

1. 캘린더 헤더·본문 모두 max-w-4xl로 통일한다. 2026-10-26의 6xl 구현보다 이번 결정이 우선한다.
2. 삭제된 OpenRouter 웹 기능의 미사용 OpenAI SDK를 제거한다.
3. .agents와 .cline에 중복된 개발 도구는 두 사본 모두 비활성 보관하고 정식 수집·검증 명령만 사용한다.

OpenAI SDK 제거는 OpenAI 공식 RSS 수집 제거를 뜻하지 않는다. RSS 출처·수집 정책·개인화 제외·문의 보류·자동화 스케줄·권한은 유지한다.

## 이력과 원본

docs/archive의 열람용 사본은 경고·상대 링크만 보정하고 과거 결론·수치를 현재 상태에 맞춰 다시 쓰지 않았다. originals 사본은 수정하지 않는다. 외부 출처 정책도 이번 문서 대조를 재검토로 간주해 날짜를 바꾸지 않는다.

비활성 도구 두 사본의 원문은 로컬 .agents/disabled에 남기고 Git에서 제외한다. 이전 커밋의 원본은 Git 이력에도 존재한다. 새 활성 도구를 개발하거나 외부 홈 스킬·Cline 설정을 수정하지 않았다.

잠금 파일을 npm으로 정리하는 동안 기존 Tailwind WASI 번들의 내부 의존성 메타데이터 6개 항목이 보완됐다. 새 직접 의존성이나 기존 패키지 버전 업그레이드는 없다. 깨끗한 npm ci로 설치 가능 여부를 확인한다.

## 검증 결과

- OpenAI SDK 제거 후 깨끗한 npm ci 성공, npm ls openai 결과 없음. 기존 패키지 버전 변경은 0건이다.
- 회귀 검사 73건·TypeScript·selfcheck·제품 빌드 통과. 기존 Tailwind sourcemap 경고는 남으며 빌드 실패가 아니다.
- 원본 보존 폴더를 제외한 현행·열람용 이력 문서 25개의 상대 링크 검사: 깨진 대상 0건. originals는 원본 상태 보존을 위해 검사·수정에서 제외했다.
- 320/1024/1440px 브라우저에서 헤더와 캘린더 본문의 좌우 위치·폭 일치. 가로 넘침 없음, 브라우저 오류 로그 0건. 임시 화면 크기는 검사 후 해제했다.
- 시각 증거: [4xl 캘린더 정렬](../../artifacts/calendar-4xl-2026-10-28.png). 실기기·스크린리더 또는 접근성 인증을 뜻하지 않는다.
- 비활성 보관 파일은 자동 발견 이름이 없고 Git 무시 대상인 것을 확인했다. 개발 도구 자체를 실행해 정상화했다고 주장하지 않는다.

## 남은 경계

국내 공식 행사 출처 확대, 교육 조건 최신성 재검토, 실기기·스크린리더, 공개 문의 주소, LICENSE 파일, 필요 시 외부 도구 등록 상태 확인은 남아 있다. 모든 계획이 완료된 것은 아니다. 이번 로컬 변경은 마지막 공개 배포와 구분한다.
