# AI 도구함 상세 안내와 Liner Scholar

2026-11-08 로컬 작업. 카드에서 ElevenLabs 브랜드 심볼을 제거하고 도구명과 새 창 아이콘을 공식 링크로 사용한다. 상세 활용 안내는 기존 애니메이션 대화상자와 배경 흐림, Escape·바깥 클릭 닫기 및 초점 복원을 사용한다. 11개 도구의 안내는 편집한 고정 예시이며 개인화나 자료 자동 연동이 아니다. AI 소식 링크는 전체 화면으로 이동하므로 논문 분야를 직접 선택하도록 안내한다. 기능 태그에는 자체 기능별 선 아이콘을 사용한다.

Liner Scholar는 2024년 라이너 학술 모드에서 발전한 별도 서비스다. ScholarAI와 동일하다는 근거는 확인하지 못했다. 공식 자료와 무료 범위는 출처 관리표를 따른다. 계정 기반 실제 이용, 상세 조건·응답 품질 전수 검증은 하지 않았다.

검증: 단위 검사 116건 통과·1건 건너뜀, lint·selfcheck·빌드 통과, 데스크톱·모바일 도구함 회귀 2건 통과(공식 링크·팝업·Escape·초점 복원·검색). 실제 스크린리더·실기기는 미검증. 기존 빌드 번들 크기 및 소스맵 경고가 있다. 원격 푸시·배포는 이번 작업 범위에 포함하지 않는다.
