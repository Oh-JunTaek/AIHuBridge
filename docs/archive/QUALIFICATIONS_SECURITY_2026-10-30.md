# 자격증 탐색과 보안 자료 확장

- 자격증 목록을 좌측 필터와 목록으로 재구성하고 가나다·영문 순서로 정렬했다. 분야를 AI·데이터·클라우드·보안·컴퓨터 활용·개발로 묶었다. 컴퓨터활용능력은 목록에서 하나로 표시하고 상세에서 1·2급을 선택한다. 기존 상세 주소는 유지한다.
- 홈 버튼을 연한 하늘색으로 바꾸고 데스크톱 페이지 이동에도 짧은 등장 효과를 적용했다. 움직임 축소 설정은 유지한다.
- Microsoft SC-900, ISC2 CC 자격과 Microsoft의 AI 보안·사이버 보안 학습 경로를 공식 링크 기반으로 추가했다. 시험 비용, 한국 예약 여부와 학습 조건은 공식 페이지에서 확인하도록 안내한다.
- AI 소식에서 보안 관련 키워드를 선택해 기존 수집 자료를 찾을 수 있다. 별도 보안 출처 수집은 추가하지 않았다.
- 검증: 테스트 92개, 타입 검사, selfcheck, 빌드 통과. 로컬 브라우저에서 목록과 컴퓨터활용능력 급수 선택을 확인했다. 모바일 실기기는 미검증. Tailwind 소스맵 경고가 있다. 원격 미반영.
