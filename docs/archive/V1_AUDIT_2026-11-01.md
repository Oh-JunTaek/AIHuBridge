## 확인된 문제와 주의점

1. **자동 갱신 범위 차이:** 뉴스·행사는 예약 갱신하지만 교육·수료·시험 조건과 국비 회차의 자동 검토는 미구현이다. 국비 예시는 시작일 이후 숨긴다. 최근 보강한 대체 자료는 알려진 종료일이 지났을 때 선택되며 링크 오류·조건 변경을 탐지하지 못한다. 고용24 API의 개인 명의 이용·공개 운영 허용 여부 확인이 필요하다.
2. **SNS 최신성:** 2026-11-01 공개 화면에서 오래된 2025년 게시물이 상단에 표시됐다. 공개 API 표본에서도 Hugging Face와 Thomas Wolf 계정의 최근 응답에 2025년 글이 있었고 Anthropic은 빈 목록이었다. API가 현재 오래된 글을 응답한 관측이지 플랫폼 전체 장애라고 단정하지 않는다. 기본값은 가져온 전체이고 3개 계정·한 플랫폼에 제한된다. 계정별 최신 활동 여부·원문 날짜와 재게시 시각 구분을 추가로 확인할 필요가 있다.
3. **컴퓨터활용능력 공식 링크:** 등록 주소는 `?mm=22`로 이동해 페이지 상단에 워드프로세서가 표시되지만, 본문은 컴퓨터활용능력 내용이다. 공식 메뉴의 컴퓨터활용능력 링크는 `?cd=0103&mm=21`이다. 사용자가 다른 시험 페이지에 온 것으로 오해할 수 있어 링크를 정리할 필요가 있다. 다른 링크 전수 조사 결과는 아니다.
4. **Pretendard 요청 실패:** `index.html`의 Google Fonts 주소는 로컬 HTTP 확인에서 400을 반환했다. 브라우저는 대체 글꼴을 사용한다. 글꼴 전체 변경은 사용자가 최종 선택까지 보류했으므로 임의 교체하지 않는다.
5. **직접 주소 HTTP 응답:** 공개 `/path?...`와 `/qualifications`는 서버 차원에서 404를 응답하지만, 커리큘럼 직접 주소는 GitHub Pages 404 문서의 앱 로딩으로 브라우저에서 상세 팝업이 열렸다. 일반 브라우저 접근 성공과 검색 엔진·링크 미리보기의 404 처리는 구분해야 한다. 다른 모든 주소·클라이언트에서 검증한 것은 아니다.
6. **운영 결정·권리:** 문의 이메일의 보관·삭제 기준과 다른 외부 이미지·글꼴 이용 조건은 별도 확인 대상으로 남아 있다. 사용자 결정으로 기관·기업 로고는 자체 그림으로 대체한 상태다.
