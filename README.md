# AI 허브릿지

AI 뉴스·학습 커리큘럼·인증기관 교육·다양한 AI 일정을 연결하는 한국어 웹 서비스입니다.

- 운영 주소: https://oh-juntaek.github.io/AIHuBridge/
- 학습 경로: https://oh-juntaek.github.io/AIHuBridge/path
- 사용자 확인상 기존 배포는 정상 동작합니다. 로컬 수정의 푸시·배포는 별도 요청 후 진행합니다.

## 현재 기능

- AI 뉴스: 공식 RSS 기반 정적 JSON, 분야·언어·출처·검색 필터, 발행일·최종수집일 표시, 장애·실제 0건·오래됨 구분 및 재시도.
- 학습 커리큘럼: 공식 교육·인증으로 이어지는 4단계·16항목과 난이도·분야 필터.
- 인증기관 교육: 24개 항목의 유형·언어·비용·검색 탐색. 학습 비용과 응시·수료증 비용, 참여 조건·검토일·공식 근거를 구분합니다. 미확인을 무료로 표시하지 않습니다.
- AI 캘린더: 교육·세미나·웨비나·워크숍·부트캠프·해커톤·공모전·컨퍼런스·밋업, 월간 달력·날짜별 선택·목록 전환, 유형·진행 방식·비용·신청 상태·지역·주제 필터, 24건씩 더 보기.
- 화면 설정: 한국어 전용, 라이트·다크·시스템 테마. localStorage에는 화면 설정만 보관합니다.

용어 사전·오늘의 개념·퀴즈, 학습/인증 완료 체크·진도 퍼센트·방문 통계·개인 배지는 제공하지 않습니다. 이전 버전의 기록은 이어받지 않으며 저장된 테마만 유지합니다.

메뉴는 모바일에서 줄바꿈되며 본문 건너뛰기·키보드 포커스·필터 선택 상태·다크모드·움직임 줄이기를 지원합니다. 문의 운영 주체는 eunmastudio이며 공개 문의 주소는 추후 추가 예정입니다.

부스트코스 7개와 성균관대 무료 AI 수학 2개를 추가했습니다. 학습 경로의 ‘0. 기초 쌓기’에서 AI 개념·파이썬·수학·데이터 기초로 시작할 수 있습니다. 수료증 미발급과 비용 미확인을 구분하며, 명시된 수강·학습 기간이 끝난 과정은 목록에서 제외합니다.

## 콘텐츠와 수집 원칙

- 뉴스 설명은 RSS 설명문을 규칙으로 발췌합니다. 로컬 모델·별도 추론 서버·생성형 번역이나 요약은 사용하지 않습니다.
- AI 캘린더는 RSS의 명시적 모집 일정과 제공처의 공개 행사 일정을 수집합니다. 뉴스 수집은 계속 RSS만 사용합니다.
- 신청 마감이 확인된 공고는 한국시간 기준으로 D-day와 모집 상태를 표시합니다.
- 해외 행사에서 현지 날짜만 공개되면 시각·시간대를 임의로 채우지 않습니다. 신청 마감 미확인과 개최 예정을 구분하며 D-day는 표시하지 않습니다.
- 과거·마감·취소·연기·날짜 미정·비AI 자료·중복·샘플은 제외합니다. 미확인 요금은 무료로 표시하지 않습니다.
- 출처 전체 실패 시 이전 정상 JSON을 보존하고 실패로 종료합니다. 일부 실패 시 일정은 해당 출처의 검증된 향후 일정만, 뉴스는 해당 출처의 발행 후 7일 이내 기사만 보존하고 부분 실패를 표시합니다.
- 뉴스 발행일 누락·무효·미래 날짜는 추정하지 않고 제외합니다. 제목은 보존하고 동일 URL의 추적 파라미터 변형을 중복 제거합니다. 출처 설정은 src/lib/news-sources.mjs 한 곳에서 관리합니다.
- 헤더는 투명 로고를 사용하며 다크모드에서는 밝은 단색으로 표시합니다.
- 현재 출처와 검토 근거: [수집 출처 관리표](./SOURCE_REGISTRY.md).

## 실행·검사

~~~bash
npm ci
npm run dev       # http://localhost:5173/AIHuBridge/
npm run refresh   # 뉴스 RSS + AI 일정 수집
npm test          # 날짜·실패·뉴스 응답·설정 회귀 검사
npm run selfcheck # 스키마·메타·중복·교육 참조 무결성
npm run lint      # TypeScript 검사
npm run build
~~~

## 메뉴

홈 / AI 뉴스 (/research) / 학습 커리큘럼 (/path) / 인증기관 교육 (/certs) / AI 캘린더 (/calendar) / 설정 (/settings).
개발자 메뉴와 뉴스의 진단 링크는 제거했습니다. /dev 직접 주소는 운영 진단용으로만 유지합니다.
삭제한 /quiz는 더 이상 서비스하지 않습니다. 이용약관과 개인정보 처리방침은 하단에 있습니다.

## 운영

**매일 한국시간 오전 7시·오후 7시, 하루 두 번** GitHub Actions에서 뉴스·AI 일정을 수집합니다. 개인 PC를 켜 둘 필요가 없습니다. 자료 검사·테스트·빌드를 통과한 데이터만 저장하며, 수집 성공을 받은 별도 배포 작업이 최신 master를 다시 빌드해 사이트에 반영합니다. 예약 시작은 GitHub 대기열로 지연될 수 있습니다.

뉴스·행사 일정이 자동 대상이며 인증기관의 가격·수료 조건과 학습 커리큘럼은 별도 검증하는 정적 자료입니다. 정상 운영 중 매번 수동 수집·배포할 필요는 없지만 출처 변경이나 실행 실패는 점검해야 합니다.
