# AI HuBridge · AI 허브릿지

AI 소식과 일정, 학습 자료와 자격 정보를 한곳에서 찾아보는 한국어 공개 웹 서비스입니다.

**[웹사이트 방문](https://oh-juntaek.github.io/AIHuBridge/)** · [추천 커리큘럼](https://oh-juntaek.github.io/AIHuBridge/path)

## 주요 기능

| 메뉴 | 소개 |
| --- | --- |
| **AI 소식** | 뉴스·공식 모델 발표·연구 논문을 RSS/Atom 기반으로 모아 보고, 분야·출처·언어 등을 탐색합니다. |
| **추천 커리큘럼** | 기초부터 이어지는 AI 학습 단계와 공식 교육 자료를 안내합니다. |
| **수료증 취득 강의** | 수료증 발급이 확인된 교육과정의 비용과 조건을 살펴봅니다. |
| **자격증 도전** | 자격시험과 준비 자료를 탐색합니다. |
| **학습 자료실** | 강의·실습·프로젝트와 학습 플랫폼을 탐색합니다. |
| **기업 SNS** | 공개된 기업·관계자의 Bluesky 게시물을 살펴봅니다. |
| **AI 캘린더** | 웨비나·워크숍·세미나·해커톤·공모전·컨퍼런스 등 AI 일정을 달력과 목록으로 탐색합니다. |

상단의 **학습관**에서 학습과 자격 정보를, **정보관**에서 소식·일정·기업 SNS를 선택합니다.

AI 캘린더의 기본 ‘국내·온라인’은 국내 행사와 전 세계 온라인 행사를 포함합니다. 비용·마감·개최 시각 등 확인되지 않은 정보는 임의로 추정하지 않습니다.

## 서비스 원칙

- 로그인·개인 학습 기록·개인화 추천과 화면 설정 저장 없이 사용하도록 설계했습니다.
- 소식 본문 전체를 복제하지 않고 출처와 원문 링크를 제공합니다. RSS 설명은 규칙에 따라 발췌하며 생성형 AI 요약·번역 기능은 제공하지 않습니다.
- 뉴스 및 AI 일정은 GitHub Actions로 한국시간 매일 오전 7시 1회 예약 갱신하는 설정을 제공합니다. 실제 수집 시각은 지연될 수 있습니다.
- 출처·가격·수료 조건은 제공처에서 바뀔 수 있으므로 최종 내용은 공식 원문을 확인해 주세요.

## 로컬 실행 (개발자)

필요 환경: Node.js와 npm. 실제 지원 버전은 저장소 설정을 확인하세요.

```bash
npm ci
npm run dev
```

```bash
npm test
npm run lint
npm run selfcheck
npm run build
npx playwright install chromium
npm run test:e2e
```

AI 소식은 최근 7일을 기본으로 보여주고, 게시 기간을 바꿔 일반 소식 30일·모델 소식 90일·논문 180일의 보관 자료를 검색할 수 있습니다. 지난 행사·공고는 30일 보관하며 선택해서 표시합니다. 취소·연기는 기본 달력에도 상태를 표시합니다. 상세 기준은 [자료 갱신·보관 정책](./docs/standards/CONTENT_LIFECYCLE.md)을 따릅니다. 2026-10-28 운영 사이트 반영과 자동 수집·후속 배포 연결을 검증했습니다.

배포 환경은 GitHub Pages 하위 경로 `/AIHuBridge/`를 사용합니다.
