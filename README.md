# AI HuBridge · AI 허브릿지

한국어로 AI 소식, 학습 경로, 교육·인증, AI 일정을 한곳에서 찾아보는 공개 웹 서비스입니다.

**[웹사이트 방문](https://oh-juntaek.github.io/AIHuBridge/)** · [학습 경로](https://oh-juntaek.github.io/AIHuBridge/path)

## 주요 기능

| 메뉴 | 소개 |
| --- | --- |
| **AI 소식** | 뉴스·공식 모델 발표·연구 논문을 RSS/Atom 기반으로 모아 보고, 분야·출처·언어 등을 탐색합니다. |
| **학습 경로** | 기초부터 이어지는 AI 학습 단계와 공식 교육 자료를 안내합니다. |
| **교육·인증** | 교육 과정·자격시험·역량 인증을 비용·언어·조건과 함께 비교하고 원문을 확인합니다. |
| **AI 캘린더** | 웨비나·워크숍·세미나·해커톤·공모전·컨퍼런스 등 AI 일정을 달력과 목록으로 탐색합니다. |
| **설정** | 화면 테마를 선택합니다. |

AI 캘린더의 기본 ‘국내·온라인’은 국내 행사와 전 세계 온라인 행사를 포함합니다. 비용·마감·개최 시각 등 확인되지 않은 정보는 임의로 추정하지 않습니다.

## 서비스 원칙

- 로그인·개인 학습 기록·개인화 추천 없이 사용하도록 설계했습니다. 화면 테마 설정만 브라우저에 저장합니다.
- 소식 본문 전체를 복제하지 않고 출처와 원문 링크를 제공합니다. RSS 설명은 규칙에 따라 발췌하며 생성형 AI 요약·번역 기능은 제공하지 않습니다.
- 뉴스 및 AI 일정은 GitHub Actions로 한국시간 하루 2회 예약 갱신하도록 구성되어 있습니다. 실제 수집 시각은 지연될 수 있습니다.
- 출처·가격·수료 조건은 제공처에서 바뀔 수 있으므로 최종 내용은 공식 원문을 확인해 주세요.

## 로컬 실행 (개발자)

필요 환경: Node.js와 npm. 실제 지원 버전은 저장소 설정을 확인하세요.

```bash
npm ci
npm run dev
```

```bash
npm test
npm run lint
npm run selfcheck
npm run build
```

배포 환경은 GitHub Pages 하위 경로 `/AIHuBridge/`를 사용합니다.
